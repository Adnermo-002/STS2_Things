# Thief Raider v8 生产约束

v7 仅保留为失败证据。本目录是新的干净生产链；在全部 Gate 通过前，不向
`animations/`、PCK 或 Steam 复制任何资源。

## 1. 母图 Gate

- 稳定朝屏幕左侧的 3/4 侧视；头、胸、髋、膝、脚尖与武器方向一致。
- 比例介于 Axe/Crossbow Ruby Raider 之间；不得写实长身，也不得大头 Q 版团块。
- 保留灰黑兜帽、黄色眼睛、短匕首、战利品袋和暗酒红软布。
- 保留原色系；禁止整图滤色。
- 哑光、平滑、低频大色块；删去多面体小切面、塑料高光和密集饰件。
- 先在真实战斗缩放下与 Axe/Crossbow/Brute 同屏通过，再进入分件。

## 2. 分件 Gate

- 所有可见像素及隐藏延伸必须来自同一身份、同一视角、同一光照的母体设计。
- 四肢是闭合实心、自然延伸的重叠形状；禁止空心袖筒、靴筒、插口或方块断面。
- 每个关节只保留 12–24 px 的克制重叠，不使用整块 `body_underpaint` 兜底。
- `parts/` 中 PNG 数量必须与 manifest 一致；禁止旧轮次残件混入。
- 总隐藏延伸面积不得超过母图 alpha 面积的 18%。
- bind 重组要求 Alpha IoU >= 0.995、RGB MAE <= 2/255；该指标只证明 bind，不替代动作审查。

## 3. Rig Gate

- 主链：`root -> cog -> pelvis -> torso_lower -> chest -> neck -> head`。
- 双臂和双腿各有 IK 目标；脚底锁地，匕首尖端有接触目标。
- 披风至少三段 weighted mesh；围巾至少两段；袋子、袋绳分别有惯性控制。
- 硬附件使用刚性 slot；软组织使用 mesh/weights。
- 攻击、死亡等跨身动作必须有显式 draw-order 时间线。

## 4. 首批动作 Gate

只先批准 `attack`、`hurt`、`die`：

- `attack`：总长 1.05–1.15s；后坐蓄力 -> COG 推进 -> 0.45–0.50s 接触 -> 2–3 帧命中停顿 -> 回弹；
  接触帧最左轮廓必须比 bind 至少多伸出 28 px。
- `hurt`：0.52–0.68s，方向清楚、短促压缩与回弹；战斗缩放下质心位移至少 5 px。
- `die`：1.15–1.35s；失去支撑、膝塌、侧伏、落定；最终质心下移至少 55 px，脚底不得漂浮。
- 任一采样帧不得出现关节洞、断肢、暗补片、披风穿脸或附件漂浮。

三条动作通过后，再制作 `idle_loop/cast/summon/power_up/revive`。Idle 只允许受控呼吸、
视线和局部软组织滞后，不做全身周期扭动。

## 5. 集成 Gate

- Godot/Spine 4.2 实载逐帧渲染通过。
- 战斗场景检查 intent、血条、卡牌、瞄准箭头、相邻怪物、召唤物和 VFX 图层。
- 动画只读取视觉时间，不读取或写入战斗 RNG/状态，保持多人确定性。
- 全部通过后才构建 PCK 并安装到 Steam。
