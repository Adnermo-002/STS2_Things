# 已接受的项目选择

这些是截至 2026-10-07 的继续制作上下文，不是不可修改的长期限制。用户新要求与当前源码优先；具体数值、阵容扩充、版本与文件路径去项目核实。

| 内容 | 已确认选择／延续时需要保留的语义 |
| --- | --- |
| 深处 | 与巢穴并列的正式第二章候选，按原版章节流程生成地图、遭遇、事件、Boss 与存档；活体巨岩可在两章遇到 |
| 洞穴场景 | 多套完整场景，新区域地板全新生成，略亮方便看清；鱼类用河湾洞穴，火堆单独场景，座位贴合原角色坐姿 |
| 大地图 | 专属石板纹理，自然连贯；用户最终选回第一版，不能默认拿后续更精细版替换 |
| 灯笼鱼 | 是参考原版漂浮鱼的灯笼鱼，已取消鱼人造型；圆润略卡通，弱池两条、强池三条，也允许已接入的混合阵容 |
| 致盲 | 下 N 张抽到的牌临时随机为 1–3 费，卡面花屏与乱码有持续变化；当前玩家回合结束恢复。实际费用／牌状态与本地视觉各有归属，视觉不消费玩法 RNG |
| 血蛭 | 单种弱／强池基础为两／三只；混合遭遇按当前 Encounter。寄生开场及补牌直接入手牌，无固有；留到回合结束给存活血蛭各两层再生和力量 |
| 再寄生 | 内部调度 Buff 不展示；寄生被消耗后当前回合意图不变，下回合插入塞牌，随后恢复被打断的正常循环，避免不断从头循环 |
| 吸水海绵 | 蓄水通过身体水位和膨胀显示，不只是图标。喷水后退水、回复，冲净让下一张抽到的状态牌消耗；“冲净改成状态牌”曾被明确纠正，不应据旧句把能力做成状态牌 |
| 垂丝蛾 | 弱、强池均可出现；先给玩家 Buff，下回合正常抽牌完成后随机捆两张手牌。解除不减费；卡面做真实绕丝效果，可参考 Queen 管线，但不模仿锁链外形 |
| 馋嘴洞胃 | 弱池单只、强池搭配其他怪，皮厚且初始攻击相对低；投食两张带保留的原版碎屑，下一回合吞食玩家状态牌。吞牌后按原版清理原手牌节点；继续制作见 `docs/cave-maw.md` |
| 菌根双生子 | 深处精英，一只专精攻击、一只专精防御，并施放不同方向的强化；交换生命时同步强壮／弱小体态及数值，一只被击杀后另一只狂暴。细则见 `docs/mycorrhizal-twins-20261004.md` |
| 收音水母 | 深处精英，只收攻击与技能牌；收音为层数能力，有独立强化层数的回合，多人分别记录再按原生规则回放。细则与后续数值查询 `docs/radio-jellyfish-stacks.md` 及当前源码 |
| 三种蜗牛 | 晶壳破壳后不再缩壳并奖励晶片；涎丝只修仍有壳的盟友，无目标改为攻击；爬岩真实向玩家爬行，破壳使重击推迟 |
| 人面柱 | 三层在场，后备层替补并扣可见层数；石饼实际垒高。上／下顺时针、中层逆时针转脸，起手错峰；上／中／下分别免伤、半免伤、正常受伤。正常受击／攻击主要前后晃，击破后的上层明确下落和眩晕；不同脸是装饰，不另加能力。继续制作见 `docs/human-face-column.md` |
| 余影魔 | 与一代倏忽魔有联系，四臂、999 生命、五次行动后消散；玩家攻击实际伤害转换为所属玩家格挡。后续明确选择白色反色、深色裂隙，沉静诡异即可，不必太呆萌 |
| 活体巨岩 | 接触按真实玩家队形；收招稳定，特殊偷牌有张掌抓握动作。共享老化从两层计数，击倒任一手臂扣层，归零赠牌后重置；抓取试炼在正常抽牌后选。曾确认只重绘 UI，继续该重绘任务时保留本体和背景 |
| 地图横路 | 锁与连接对齐节点中心，抵达任一端并完成房间后才可交互；发起者支付、整队共享。用户要求去掉无意义的同类节点横路，弹窗只保留简短开通确认 |
| 多人配置 | 房主控制、队员同步；BGM 开关关闭模组指定音乐并恢复原版音乐，战斗音效保留 |
| 实用事件已确认项 | 遗物修补摊出售遗物给 200 金币；药水试饮会给随机药水；窄门前三项直接展示各自移除的牌，第四项为“换个姿势”。这些是各自事件的选择，不是统一奖励模板；继续制作见 `docs/practical-depths-events.md` |

这是语义索引，不是完整实现文档。按对应模型、最新制作记录和本轮需求更新；历史助手草案不覆盖用户之后的纠正。
