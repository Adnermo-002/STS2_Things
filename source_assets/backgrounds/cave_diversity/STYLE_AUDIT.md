# 多样洞穴与提亮 · 自审记录

结论：新增四套与已有四套明亮版均通过视觉自审和本次资源检查。

## 多样性与画风

新增洞穴分别以天光石拱、横向河湾、侧壁晶簇和菌根洞室构成轮廓。地面与洞体均独立生成；不是同一套岩柱的换色，也未取回之前的原版地板。画法继续参考项目中不规则岩石边缘、简化手绘色面和低干扰的战斗背景。

| 场景 | 检查重点与结果 |
|---|---|
| 天隙岩厅 | 左侧洞顶天光和右侧冷色通道形成不同空间关系；明亮岩台保持平整，洞顶仍有暗色层次。通过 |
| 回水石湾 | 横向低岩檐与后方地下水面区别于柱林；中前方是宽阔干燥战斗平台，没有横穿站位的水沟。通过 |
| 白晶裂窟 | 两侧乳白晶簇清楚可辨，晶体以手绘色面表现；中央区域没有挡路晶体、强泛光或密集装饰。通过 |
| 根垂菌洞 | 垂根、菌伞和后方洞穴互相区分；菌伞位于战斗区域后侧，土岩地面留出完整站位。通过 |

初稿中天隙开口太靠上，白晶和菌洞的主要晶簇 / 菌伞太靠外侧，无法稳定保留在游戏的中心裁切中。这三套退回构图调整：下移并围合天隙开口，将主要晶簇和菌伞向中心移入。终稿重新检查普通、超宽和 4:3 画幅。

## 亮度检查

现有四套通过仅作用于绘景的材质提升暗部和中间调；色彩、透明度与前后景层次保留。对照实际截图，岩壁孔洞、地表沟槽和远景比此前更容易看清，没有整片发白或明显截断的高光。

| 场景 | 原灰度中位数 | 提亮后灰度中位数 |
|---|---:|---:|
| 幽蓝溶洞 | 33.67 | 49.60 |
| 苔光岩窟 | 31.02 | 46.42 |
| 余烬石窟 | 26.20 | 40.11 |
| 紫雾深窟 | 29.43 | 44.21 |

数值是截图 RGB 加权灰度的诊断值，范围为 0–255，不作为画风相似度评分。新增场景按各自光源关系绘制更清晰的中间调，天光石厅自然比封闭菌洞更亮。

## 原生验证

- 八套场景都在 Godot 4.5.1 / D3D12 / Forward Mobile 中渲染了 1920 × 1080、2560 × 1080、1440 × 1080。
- 原生明暗材质已在实际渲染中工作；它仅附着于背景绘景，不是屏幕全局后处理。
- 第 00 层为全不透明 2048 × 960 PNG；新场景的前景遮雾层保留真实 alpha。
- 每套另取相隔 120 帧的截图确认环境效果实际运动。
- 合并 PCK 共 127 项资源，重新挂载后 32 个真实图层全部加载并实例化成功。
- 实际渲染无资源、脚本或 shader 错误。D3D12 的 PSO caching 提示属于引擎警告。

新增前景只承担静态遮挡，不具备移开后完整露出底图的能力；新增河湾水面为绘景。验证范围是背景素材、真实背景渲染和打包加载，没有运行实战。
