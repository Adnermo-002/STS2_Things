# 深处营地画风与坐姿复查

最终营地为独立绘制的避风洞穴，有低矮岩棚、侧方通道、旅行行囊、四个承坐面和中央火塘。与灯笼鱼的地下河湾战斗背景分开。石壁、地面、石凳和火塘均来自本次新生成绘画。

画风参考项目已经审核的原版式岩石画法：概括大色块、低频笔触、不规则轮廓、克制的暖灰与冷蓝层次。没有使用写实摄影、3D家具或浓重漫画线条。角色和原生火焰叠入后复查整体比例、明暗和边缘关系。

首版整图座位过高、过靠外，未通过原生坐姿检查。第二轮根据原生四人坐姿指导图重绘石凳；随后拆出四个不同形状的石凳和火塘，补绘干净地面，在场景中分别定位，以消除整图生成的坐标偏差。没有移动、缩放或重画原版人物来掩盖错位。

原生人物根节点保持 `(650.8,715.8)`、`(1264.8,722.8)`、`(775.8,658.8)`、`(1117.8,656.8)`，缩放 0.5。承坐面按人物臀部与衣袍接触位置定位，前排腿部留有空间；后排保持原版遮挡关系。已检查单人、四人以及熄火状态，最终截图位于 `build/depths/camp_review`。

火焰和暖光使用原生休息流程控制的 `RestSiteLighting`，熄火不会移除座位和火塘。火焰保留原版 stepped-fire 的视觉算法，VisualShader 转成其原生生成的等价静态 shader，避免测试宿主退出时的动态图材质释放问题。

生成路径：用户指定接口，imagegen CLI `gpt-image-2`，high。提示词：`camp_prompt.txt`、`seating_revision_prompt.txt`、`empty_floor_prompt.txt`。`camp_seats_source.png` 为原始新绘家具，`camp_final.png` 为补绘后的背景底板；`props.json` 和 `split_camp_props.py` 保存分层定位数据，运行资源在 `images/rooms/depths_camp` 与 `scenes/rest_site/depths_rest_site.tscn`。

结论：最终坐姿、场景分工与画风对照检查通过。此结论为人工视觉自审，不使用虚构的画风相似度分数。
