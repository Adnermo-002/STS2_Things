# Cave God 界面素材重绘

用户确认保留 Boss 本体贴图和洞穴背景，仅重绘界面图像。

已准备 14 个独立生成任务：8 个能力图标、5 张卡面、1 个 Boss 头像母图。头像母图将生成地图图标、战斗记录头像及描边；图标将生成 256 px 原图和 64 px 打包图。原版通用力量、易伤、岩石铠甲等共享资源不作全局替换。

`generation-manifest.json` 列出每项任务、输入语义参考、原版风格参考及目标路径；`prompts/` 保存完整提示词；`references/` 为原版风格对照；`before/` 为原界面图像备份。

使用用户指定的 `gpt-image-2.5-sunburst`，通过 imagegen 官方 CLI 和 https://cpa.yuseus.io/v1/ 调用。14 个最终母图共调用 15 次，首版碎晶未通过画风自审，已重画并采用第二版。

2026-10-05 用户明确确认素材外发与该接口鉴权授权后完成生成。`masters/` 保存九个透明图标／头像母图；`integrated-assets.json` 记录 32 个运行时及制作文件的尺寸和哈希。完整自审记录见 `docs/cavegod-ui-art-20261005.md`，所有图像均已对照原版并检查原生 UI 渲染。

这里不保存 API 密钥。
