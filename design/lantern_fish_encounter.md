# 深处：三条灯笼鱼

> 数值已在 1.25.2 按原版第二章提高；本文原始设计数值保留为制作记录，当前完整数值与验证见 [深处数值校准](../docs/depths-balance-20261006.md)。

已正式接入第二章「深处」：三条灯笼鱼的 `LANTERN_FISH_ENCOUNTER` 位于强怪池，两条灯笼鱼的 `LANTERN_FISH_WEAK` 位于弱怪池。详见 [章节接入说明](depths_act_integration.md)。根据最终反馈，怪物完全改成漂浮鱼类，取消人形手脚，参考原版灵魂鱼的圆钝造型、迟钝表情、局部深色轮廓和柔和手绘色块。鱼类固定使用新画的回水石湾及新生成地板；营地使用独立构图。

## 数值与回合

| 项目 | 普通进阶 | 对应高进阶 |
| --- | --- | --- |
| 单条生命值 | 38–42 | 42–46 |
| 啮咬 | 6 伤害 | 7 伤害 |
| 耀闪 | 每名存活玩家 2 层致盲 | 不变 |
| 甩尾 | 4×2 伤害 | 5×2 伤害 |
| 收灯 | 自身 9 格挡 | 不变 |

循环为「啮咬 → 耀闪 → 甩尾 → 收灯」。三条鱼分别从第 1、2、4 招开始。完整三鱼组的前三个敌方回合各有一条耀闪，第四个回合没有新增致盲。击杀正在准备耀闪的鱼可减轻后续压力。

## 致盲

接下来的 N 次**实际抽牌**消耗计数，上限 6。普通能量牌在抽到时使用原版战斗费用 RNG，等概率变成 1、2、3 费；只掷一次。花屏和乱码使用独立视觉时钟，每秒变化，不重新掷费用。

受影响的牌遮挡原画、名称、描述，费用和牌型保持可读。费用与遮挡持续到当前玩家回合结束，通过原生 `EndOfTurnCleanup` 恢复；打出、弃掉、复制、重抽均不提前结束。计数耗尽后，已受影响的牌仍持续到回合末；未用完的抽牌计数保留。

X 费与不可打出的牌保留特殊费用规则，仍消耗计数并受到视觉干扰；星能不变。原版全局费用修正正常生效，人工制品可抵挡致盲。生成到手中的牌、被禁止的抽牌以及满手时未实际抽到的牌不消耗计数。不修改卡牌模型描述、不替换附魔或异变槽位。

## 画风与动画自审

最终采用 [纯鱼形原画](../source_assets/monsters/lantern_fish/floating_fish_final.png)。早期人形、压眉和尖牙版本已弃用，最终只有鳍、尾和柔软灯须；厚嘴唇与两颗小钝牙表达呆滞感，危险感来自灯囊的耀闪。

自审结论：通过本次对照检查。检查了原版 `soul_fysh` 的色块、轮廓与笔触，最终原画在真实战斗尺寸下没有黑色漫画重描边、密集鳞片、写实尖牙或人形肢体。检查了新地板与洞穴的中间亮度，灰青鱼身、米黄腹部、琥珀灯囊均可辨认。原画与原版参考并排证据见 [画风对照](../build/lantern_fish/review/style_comparison.jpg)。

24 根 Spine 骨骼，10 组动作。悬浮、摆鳍、尾部、下颌和八节灯须分别驱动；不是整张图片平移抖动。耀闪为跟随灯囊的局部暖光，不闪烁整屏。双击分别播放完整甩尾动作，接触时间与伤害结算对齐。骨骼源工程见 [LanternFishRig](../tools/LanternFishRig/README.md)。

生成方式：用户指定接口，imagegen 技能 CLI `gpt-image-2` / high；最终[完整提示词](../source_assets/monsters/lantern_fish/floating_lantern_fish_prompt.txt)。原版鱼类贴图仅作风格参考，角色像素为新生成。重建不需要 API 密钥。
