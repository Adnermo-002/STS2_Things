# 馋嘴洞胃动画细化 · 1.16.1

本次重做绑定和动作节奏，沿用已完成的洞胃原画。仍为弱池单只、强池搭配血蛭与垂丝蛾，投食两张保留碎屑。

## 绑定调整

- **连续舌头**：由 7 节串联骨骼改为沿连续曲线驱动的 9 个控制骨骼。网格按纵向位置混合相邻控制，伸缩分布到整条舌头，避免把位移挤在一小段里。
- **固定舌根**：舌根跟随口内连接点的位置，方向由舌头曲线控制。唇缘的局部倾斜不会被放大成舌尖的大幅摆动；咬合时主动收舌、压低舌尖。
- **牙眼贴合**：牙齿、眼睛和眉弓跟随唇缘实际变形后的位置与方向。牙齿保持刚性，牙根补绘遮挡并放在唇缘之后，减少漂浮、错位和切片感。
- **完整落地边缘**：从原画提取整条弧形下沿并固定，不再只固定最底部的一小条水平区域。两侧与前沿都保持贴地。
- 共 **51 根骨骼、10 个绘画层、11 组动作**。控制逻辑在制作阶段烘焙为普通 Spine 4.2 位移、旋转和缩放轨道，游戏不需要运行 Python 或额外求解器。

## 动作节奏

| 动作 | 调整 |
| --- | --- |
| 待机 | 6 秒循环，唇缘、咽口和舌头错相起伏；加眉弓观察与两次错开的眨眼。 |
| 啃咬 | 张口蓄势、收舌、短暂咬合停留，再让嘴角和甲片稍晚回位。 |
| 投食 | 两次不同力度的弹舌，与两张碎屑的表现相呼应；眼睛与眉弓先抬起，再恢复。 |
| 吞食 | 先张口吸入，舌头逐渐回撤；卡牌靠近后分两段吞咽，最后收口、回弹。 |
| 挤压 | 第一段偏左、第二段偏右，增加中间回势；舌头在压口期间收起。 |
| 吃空 | 小幅探舌和不对称抬眉，随后眨眼，区别于成功吞食。 |
| 强化／受击 | 分别表现局部鼓起与短促凹陷，随后逐段复位。 |
| 死亡／复起／出现 | 闭眼、回舌和塌口分阶段进行；复起从闭合姿势展开。 |

原有命中、投食、强化结算时刻继续沿用：啃咬 0.48 秒，投食从 0.54 秒开始，挤压 0.44／0.80 秒，吞食强化在 1.40 秒。

卡牌吞入效果读取原生 Spine 的播放进度，跟随快速模式中的时间推进；回到待机时结束残留飞牌。视觉结束不阻塞游戏结算。
