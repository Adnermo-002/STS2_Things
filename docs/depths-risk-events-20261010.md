# 会咬人的宝箱与满员的病房

2026-10-10 本地开发版 **1.25.14**。两个事件已加入深处普通事件池，默认启用，可在 BaseLib／RitsuLib 配置页分别关闭。完整运行包已安装到本机，四文件哈希核实一致；**本轮未发布 Steam 或 GitHub**。

## 选项

| 事件 | 选择 | 效果 |
| --- | --- | --- |
| 会咬人的宝箱 | 伸手 | 50% 获得随机稀有遗物；50% 失去 20 生命并获得原版诅咒「受伤」 |
| 会咬人的宝箱 | 撑住箱盖 | 失去 16 生命，获得随机普通遗物 |
| 会咬人的宝箱 | 捡起金币 | 获得 25 金币 |
| 满员的病房 | 彻底治疗 | 回复全部生命，获得原版诅咒「受伤」 |
| 满员的病房 | 局部麻醉 | 回复 25 生命，接下来两场战斗首回合少抽 2 张牌 |
| 满员的病房 | 拿些绷带 | 回复 6 生命 |

概率、代价和所得在选择前直接展示。宝箱沿用原生致命伤害提示；死亡后不继续领取遗物或诅咒。对应遗物池耗尽时锁定领取选项，仍可捡金币。完成后的继续按钮不再发奖。

麻醉由事件遗物 **麻醉记录 / Anesthetic Chart** 显示剩余次数。本场开场抽牌被减少后记为生效，战斗结束消耗一次，归零后灰置；后续回合、通过卡牌抽牌和队友抽牌不受影响。其他原版开场抽牌修正仍使用同一原生流程。强制重复事件时延长已有记录，不重复添加遗物。

## 原生流程与保存

两个事件为个人选择，各自结算，使用 `EventModel`、`EventOption` 和原生历史／结束页。宝箱使用事件种子 RNG；只在领取时调用原版 `RelicFactory.PullNextRelicFromFront` 和 `RelicCmd.Obtain`。生命、金币和诅咒采用 `CreatureCmd`、`PlayerCmd`、`CardPileCmd.AddCurseToDeck<Injury>`，没有手工创建卡牌显示节点。

麻醉使用原版准备背包的 `ModifyHandDraw` 入口，通过 `AfterModifyingHandDraw` 与 `AfterCombatEnd` 标记及结算。次数和本场标记采用 `SavedProperty`；补齐 V107.1 必需的自制类型缓存注册，二进制保存往返保留两个值。事件遗物按原版规则不可交易。

源文件：[`BitingChest.cs`](../STS2_Things/Events/BitingChest.cs)、[`CrowdedWard.cs`](../STS2_Things/Events/CrowdedWard.cs)、[`AnestheticChart.cs`](../STS2_Things/Relics/AnestheticChart.cs)。

## 插画修订与自审

用户要求不出现人类，并指出最初几版的亮部细节、泛化大色块画法与原版不符。最终病房医生为戴镜片的蜗牛，病床居民是非人类洞穴生物。

重新实际查看沉没宝库、玩偶室、深渊浴场、茶师、药水信使、脑蛭、兰维德长者、共生体、发光唱诗班、饥饿蘑菇和战争史家，并放大角色局部。原版各插画细节密度不同，不能统一归结为大色块。修订改用具体主体的轮廓、内部线条、褶皱、壳纹、材质与局部明暗作参考。

宝箱选用第 3 版；病房最终选用第 6 版，保留自然的壳纹、身体褶皱、布料缝线，扩展暗处房间并去除围绕主体的黑色开窗轮廓。最终主体、原版参考及原生界面裁切已经实际查看；中间拒绝版本保留为过程记录。

原图由本轮授权的**内置 image_gen**制作；准确模型名未由工具暴露，不能写为 Sunburst。提示词、历次原图、选择和哈希记录、未渐暗原画、独立遮罩与最终肖像保存在：

- `source_assets/events/biting_chest_20261010/`
- `source_assets/events/crowded_ward_20261010/`
- `source_assets/relics/anesthetic_chart_20261010/`

运行肖像为 3440×1616，外围保留房间延伸、按实际视口连续渐暗；没有额外固定边框。麻醉记录为 256 大图、85 小图和 85 白色描边，由原生遗物组件负责计数及状态显示。

准备入口：`scripts/prepare-depths-risk-events.gd`、`scripts/export-depths-event-relic-icons.gd`。生成记录写明真实工具和加工入口。制作规范补充了对照多张原版插画、放大主体局部审核的要求，并同步到已安装 Skill。
