# 尖塔：琐事 / STS2 Things v1.25.7

支持 / Supports **Slay the Spire 2 v0.107.1 and v0.111.x**.

## 中文

同步当前完整模组源码与资产，提供同一套自动选择游戏版本的统一包。

- 包含第二章「深处」的怪物、精英、事件、场景、地图及相关机制。
- 深处普通事件池仅保留模组事件，排除原版章节与共享事件；旧局下次抽取事件前也会清理。
- 修复涅奥异常开局存档不发遗物：仅恢复尚未领取的开局选择，防止重复发放。
- 保留墓潮蛞蝓开战音频线程修复、107.1 人面柱旋转轨道修复和原生资源／Hook 迁移。
- 人面柱单次攻击为 **10**，连击为 **5×2**；保留生命值、补层及仅原中层眩晕的规则。

**安装：**下载 `STS2_Things-v1.25.7.zip`，关闭游戏，将其中的 `STS2_Things` 文件夹放入游戏 `mods` 目录。覆盖旧版本时替换该文件夹内的四个同名文件。统一包自动识别支持的游戏版本，无强制前置依赖；已经通过创意工坊安装时，请避免同时加载另一份相同模组。

本次验证：双版本编译和内嵌实现校验；最终统一包启动、深处事件生成／读档、涅奥恢复／领取／防重复；两版各 74 项人面柱规则断言，覆盖 A0／A20、1／4 人。ZIP CRC 和四个运行文件哈希通过。此轮未另做完整实机通关或真实多机联机测试。

## English

This release synchronizes the current mod sources and assets and includes one unified package that automatically selects the supported game implementation.

- Includes the alternate second act, **The Depths**, with its monsters, elites, events, scenes, map, and mechanics.
- The Depths now uses mod-authored regular events only. Vanilla act and shared events are removed, including from existing runs before the next event draw.
- Restores Neow's opening relic choice in incorrectly completed, unrewarded opening saves, with duplicate-reward protection.
- Preserves the Gravetide Slug audio-thread fix, the v107.1 Human-Faced Column rotation-track fix, and native resource/hook migrations.
- Human-Faced Column attacks deal **10**, or **5×2** for its multi-hit move. Its health, replacement layers, and former-middle-only collapse stun are preserved.

**Installation:** Download `STS2_Things-v1.25.7.zip`, close the game, and place the included `STS2_Things` folder in the game's `mods` directory. Replace the four matching files when updating. No mandatory dependency is required. Avoid loading duplicate copies if you also subscribe through Steam Workshop.

Validation for this release: builds and embedded implementation checks for both targets; native unified-package startup, Depths event generation/restoration, Neow recovery/grant/duplicate guards; 74 column-rule assertions per target across A0/A20 and 1/4 players. ZIP CRC and all four runtime-file hashes passed. This release was not separately tested through a full live run or real multi-machine multiplayer session.

`SHA256SUMS.txt` is included with the release downloads.
