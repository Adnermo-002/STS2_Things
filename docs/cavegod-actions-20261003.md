# Cave God 动作与试炼修复 · 1.10.3

## 四项问题

1. **试炼贴图**：选择卡牌覆盖了 `PortraitPath`，但原版 `HasPortrait` 仍检查按 ModelId 推导的另一条 PNG 路径，因此有原画也被判断为无图。V111 补上检测路径覆盖；V107.1 的对应属性为 private，用仅针对 Cave God 卡牌的兼容补丁读取实际原画。补齐断刃、碎盾及两种兼容试炼的状态图标，图标从原有原画裁切生成。碎晶的原版原画别名也使用同一检测规则。
2. **右手抓取错位**：左右臂 setup 长度和局部坐标不同，直接取负 FK 角度无法得到正确右侧姿态。原先玩家握点与右拳横向相差约 149 像素。右侧抓取现统一使用 IK，并在真实 Spine 运行时中以 60 Hz 反求手腕旋转，使握点落在手掌内。
3. **右手下砸抽搐**：悬停和下砸的 IK 时间线弯曲方向不一致。省略 `bendPositive` 会默认 true，不能依赖 setup 的 false。由此产生肘部换边，单独修正手腕仍会掩盖整条手臂的大幅跳变。现明确指定弯曲方向，并展开连续旋转角度，避免跨 ±180° 插值旋转一圈。
4. **三连击伤害时序**：原版伤害命令在每击后等待普通模式 0.2 秒、快速模式 0.1 秒。之前按相对间隔等待，没有扣除这些时间，第二、三击分别累计延后。现在按动作的绝对时间等待，并在跳过等待时先提交接触姿态再发出伤害/特效。

## 可复现检查

`scripts/test-cavegod-actions.ps1` 使用原生 Spine、实际背景控制器、玩家抓取跟踪和原版伤害命令。动画逐步推进，伤害使用可控时钟；图像在始终更新的离屏视口中输出。`-NoImages` 可用于快速回归。

修复前检查明确失败：

- 两张试炼卡原画检测失败，四个试炼状态缺少图标。
- 右手握点横向偏差约 149 px；悬停转下砸时拳头瞬移约 103 px。
- 仅尝试打开 IK 后，肘部换边仍造成约 558 px 的关节位移和 124.5° 角度跳变。
- 普通模式伤害时间为 0.640 / 1.540 / 2.720 秒，快速模式为 0.640 / 1.440 / 2.520 秒。

修复后：

- 卡牌原画可识别，64 px 图标和 256 px 大图可正常加载。
- 左右侧、蓝色/愤怒两种形态的连续动作检查通过；肩、肘、腕在悬停切换下砸时的位置误差小于 0.001 px，角度误差小于 0.001°。
- 普通和快速模式均在 0.640 / 1.340 / 2.320 秒触发伤害；跳过等待时，每次伤害对应的骨骼接触姿态仍为相同时间点。
- 检查下砸逐帧连续性，并复查试炼限制、多人抓取、破爪取消、转阶段、血条和败北界面清理。
