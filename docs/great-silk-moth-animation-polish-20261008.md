# 织茧巨蛾骨骼精修 — 1.25.12

2026-10-08。精修大蛾的九套动作、分件和蒙皮，已安装本地；未发布 Steam／GitHub。基础原画、数值、阵容及连续两回合各缠两张的规则沿用 [初版](great-silk-moth-20261008.md)。

## 动作改进

- **待机**：六秒完整循环。上抬缓、下拍快，翼根先发力，翼尖和后翅随后跟进；绒领呼吸、腹部分节、触角小动作与眨眼分开处理。
- **追扑**：先拉翼蓄力，再拍翼前冲；腹部、触角、前肢和丝茧依次跟随。命中后有惯性与稳定收势。
- **施法**：前肢先收拢丝茧，再分别于 0.62／0.78 秒送丝。第二根送丝特效延后 0.16 秒，跟随真正的近侧抓握点。
- **扑翼**：两次挥拍有独立身体反应，分别对应 0.42／0.67 秒；远、近翼及后翼使用不同节奏。
- **受击、死亡、复苏、入场、强化**：增加部位反应、折翼下坠与收势，修正死亡末姿态到复苏起始姿态的接续。

触角、茧和尾丝使用不同阻尼与频率的烘焙惯性。它们是确定的 Spine 动画曲线，不是运行时物理或玩法随机数。各动作保留原有结算时机和时长，待机循环由 4.8 秒扩至 6 秒。

参考原版偷窃草蜢的动画资源，为待机切攻击、受击和回待机分别设置混合时长；短受击保持利落，收招平滑接回浮动待机。

## 分件与绑定修复

动作幅度增大后，原分件暴露了两处问题：近侧触角的一段被划入后翅，腹后翼角及连接丝残留在身体网格。它们静止时重合，展开时会变成悬浮碎片。

重新归属完整触角和翼片边缘，增加独立连接丝网格。两个前肢新增肘节，腕部、丝茧悬挂点和特效起点按原图实际抓握位置校准；连接丝的两端分别跟随远侧腕部与近侧丝茧。

当前为 **39 根骨骼、8 个加权网格**。分件重建保留原图全部 alpha 与像素；原画 SHA256 仍为 `9ead6c68dd06b2fe9830fad64239be3daa5e349aea86a3108394ddf82e6f493d`，没有重绘身份或改变配色。
