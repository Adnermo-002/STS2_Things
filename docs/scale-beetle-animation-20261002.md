# 放缩巨甲虫全套骨骼动画 · 2026-10-02

本文记录初版素材与骨架制作；当前 1.10.9 的大幅动作及连续三连鞭见 [动作增强说明](scale-beetle-impact-20261003.md)。

原来的完整 PNG 场景已替换为原生 Spine 4.2：54 根骨骼、24 个槽位、六足支撑、
两条七节触角、双颚和分层甲壳。包含待机、撕咬、鞭打、重构化、蜕壳、强化、
受击、死亡、复起、登场十套动作。

现有战斗行为已接入：撕咬用 Attack，三连触角鞭打用新增 Whip，重构化用 Cast，
蜕壳用新增 Molt。四种招式的关键姿态都与原有 **0.50 秒**结算延迟对齐。
死亡保持伏地姿态，复起从该终姿直接衔接；放大能力继续由游戏的 ScaleTo 控制。
