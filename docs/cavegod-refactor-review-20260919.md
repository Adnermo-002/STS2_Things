## 最终行为

| 部分 | 当前行为 |
|---|---|
| 手臂击败 | 立即清除所有当前分类为负面的能力，包括中毒、虚弱、易伤、灾厄和负力量；保留正面能力 |
| 核心暴露 | 普通断臂后有三次玩家行动窗口；敌方回合中毒/荆棘导致断臂也不会少给一个窗口 |
| 暴露期另一条手臂 | 第一次行动眩晕，之后反击；被击倒则改为眩晕＋回满血 |
| 苏醒 | 双臂回满血，恢复中断位置，获得 2 力量；DeadlyEnemies 为 3；显示治疗＋强化意图 |
| 正常成长 | 四招循环末尾，各实体 +2/+3 力量；有明确强化意图，力量跨阶段保留 |
| 破爪 | 解除试炼、释放玩家并取消本次重摔；不会被躯干无意图补打 |
| 原生眩晕 | 可打断手臂招式；抓握被打断时清理石爪、限制能力和抓握标记 |
| 转阶段 | 核心与双臂 HP 采用原版人数/章节缩放；不会退回单人血量 |
| 最终死亡 | 清理全部手臂与石爪，释放玩家；强制击杀一阶段核心也不会留下无法结束的遭遇 |

普通循环为：刺拳 → 单臂横扫 → 中央重砸 → 山岳固守＋成长。

二阶段循环为：双拳夹击 → 抓取与试炼 → 重摔或破爪眩晕 → 中央重砸＋成长。

同一正常循环只安排一个实体攻击，左右主攻手每轮交替。多段伤害仍属于一招。核心自身的意图与伤害统一使用核心的力量/虚弱等修正，不再借用某条手臂的数值。

## 架构与修复

- 核心维护一份原版 `MonsterMoveStateMachine`；双臂使用共用抽象实现，按核心下一招投影意图，消除三个独立循环的漂移。
- 保留具体模型名称、ModelId 与资源路径；ModelDb 全量初始化与序列化缓存通过，未增加具体模型或修改 ID。
- 抓取建立、取消、破爪、转阶段和死亡使用统一释放路径，避免孤立石爪或限制能力残留。
- 多人选牌窗口只在整组选牌外层保存/恢复 UI 层级，避免每名玩家的 finally 相互覆盖。
- 不再吞掉招式异常后继续伪装战斗正常；清理通过 finally 保证。
- 倒地/眩晕保护覆盖实际伤害路径，避免持续伤害绕过选取限制。
- 原版不可受击状态同时阻止能力接收，因此自身成长使用限定作用域接收增益；受保护目标的伤害与选取限制仍保留。
- 成长参考帝王蟹/知识恶魔的 2/3 力量档位；没有把可重复断臂照搬成帝王蟹的一次性死亡 +6 力量＋99 格挡。

设计依据见 [ADR-0002](adr/0002-cavegod-single-move-cycle.md)，数值分析见 [成长审查](../design/balance/balance-check-cavegod-2026-09-19.md)。
