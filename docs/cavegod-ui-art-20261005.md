# Cave God 界面资产重绘 · 1.17.8

本次只重绘界面：8 个自制能力图标、5 张卡面、地图头像和战斗记录头像。Boss 本体、洞穴背景、战斗数值与状态机沿用 1.17.7，包含上一版已修复的收招动画。

## 生成与自审

用户于 2026-10-05 明确确认将旧界面图像和原版风格参考发送至指定接口。使用 imagegen 官方 CLI 的 `edit`，模型 `gpt-image-2.5-sunburst`，接口 `https://cpa.yuseus.io/v1/`。凭据仅进入子进程环境，不写入项目。14 个最终母图共调用 15 次，其中碎晶首版未通过画风自审，重画一次。

- 能力图标：参照原版力量、易伤、虚弱、护甲等图标的粗黑轮廓、紧凑形状和少量色块；取消旧试炼图标的爆光和细碎背景。检查 128、64、32 px 缩放下的识别度。
- 卡面：参照原版碎屑、灼伤及试炼牌的手绘色块与阴影。首版碎晶背景过于接近低多边形渲染；第二版改为近景碎晶、集中黑色阴影和低细节背景，与其余卡面统一。
- 头像：保留石脸、厚眉、石须和青色晶冠的身份特征，简化成卡通轮廓。地图版使用白色模板，接受原版地图调色；战斗记录使用彩色小头像。
- 透明图像通过纯品红背景提取 alpha，并去除边缘底色。检查深浅底色下的边缘；卡面保持不透明满幅。

最终风格检查通过：主体、色块与缩略图清晰，未见写实材质、强烈金属反光或高密度装饰。该结论是对照原版参考的人工视觉判断，不能由像素测试代替。
