# 金币横路 · 1.11.2

每幕地图最多生成三条上锁的同层横路，分散在不同高度。生成优先考虑火堆、商店、宝箱、问号，以及下一步可进入精英的节点。横路连接同层相邻的路线，中间不跨过其他节点；不会连接起点、远古之民或 Boss。

横路两端必须是不同类型的房间，不生成宝箱连宝箱、火堆连火堆等同类连接。没有合适组合时可少于三条，不用同类连接凑数。已有存档中未解锁的同类横路会在地图加载时移除，已付费道路与访问历史保留。

抵达横路任一端并完成当前房间后，点击横路或锁可打开原版确认弹窗，支付 50 金币开通。其他位置的锁只作展示，不接受鼠标或手柄交互，也不阻挡地图滚动与画线。多人时由确认的玩家支付，整队共享；开通后仍通过原版选点／投票决定是否通行。金币不足会禁用确认按钮，取消不会扣费。

每条横路只收费一次，从购买时的所在端通往另一端。禁止返回已访问的节点，避免重复拿取同一房间奖励。离开端点后，锁立即恢复为不可交互。

## 存档与同步

路线状态由原生 `ModifierModel` 存档格式保存，原生网络动作队列负责排序和同步解锁操作。发起者由原生发送者身份决定，费用由游戏逻辑固定为 50；请求会重新校验幕、地图、所在节点、目标、金币和解锁状态。重复、过期、篡改价格或已访问目标的请求不会再次扣费。

开通后只加入一个方向的连接，维持无环地图。付费边可在地图重新生成或读档时恢复；同层多走一个房间时，历史提示按实际访问顺序定位，避免后面的房间记录错位。自由选路效果仍保留已支付的横路入口。

界面直接使用原版 `NGenericPopup`／`NVerticalPopup`、确认按钮、金币符号、锁图标及地图路径点，保留原版字体、遮罩和视觉样式。
