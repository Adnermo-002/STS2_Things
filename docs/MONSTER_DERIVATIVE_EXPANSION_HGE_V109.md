# 巢穴、荣耀与事件怪物衍生路线扩展

> 基于 [怪物衍生设计图谱](MONSTER_DERIVATIVE_ATLAS_V109.md)。主图谱为路线 A；本文为 H01-H18、G01-G17、E01-E05 补充路线 B/C。每条优先把原型识别点转化为新的玩家动词；所有空间变化、继承、倒计时与精确区间都必须在 Intent 或场景标记中公开。

| ID | 路线B | 路线C |
|---|---|---|
| H01 | **岔穴地道虫**。继承钻地与出土重击；新动词是攻击左右两处“出口”来选择它在哪个槽位出土，并把冲锋线改道穿过其他敌人；公开反制为出口血量、移动箭头和刷新后的冲锋路径。 | **矿脉地道虫**。继承地下掩体与打穿窗口；新动词是在公开的伤害区间内“掘矿”，精准命中会迫使其带矿出土并增加战利品，过量则塌方并让重击提前；公开反制为本次有效区间、塌方预览和奖励档位。 |
| H02 | **抛棘蟾蜍**。继承长棘与爆刺，但棘簇会成为可选中的相邻模块；新动词是从左侧或右侧击打棘簇，把它沿槽位抛给敌人并改变爆刺覆盖线；公开反制为抛掷箭头、落点和爆刺区域。 | **蜕棘蟾蜍**。继承爆刺后消耗荆棘；新动词是抢在蟾蜍之前处理其留下一回合的棘皮尸体，精确击碎可把棘片装到玩家下一次攻击上，放任则被其吞回并再生爆刺；公开反制为尸体倒计时与双方消费结果。 |
| H03 | **换齿啃咬机**。继承夹击、多段与晕眩主题，将左右颚轮拆成两块可攻击模块；新动词是选择拆齿顺序，使剩余颚轮与核心拼出“夹击加塞牌”或“单咬加锁牌”的公开组合招；公开反制为模块图标、组合公式和下一招预览。 | **脱轨啃咬机**。继承机械夹咬和多段；新动词是在标出的伤害区间内把它击退一格，让下一次夹击先咬沿途邻居，低于区间不移动、过量则越过邻居扑向玩家；公开反制为区间刻度、移动箭头和夹击线路。 |
| H04 | **接力猎杀者**。继承嫩化的“出牌即临时失去属性”，但肉化标记只跟随当前玩家；新动词是由另一名玩家打出预告的互补牌型来截断嫩化并把属性接回，单人模式改为相邻两张不同牌型；公开反制为持有者、所需牌型和接力顺序。 | **肉票猎杀者**。继承被嫩化夺走的力量与敏捷，却把它们凝成相邻的可攻击肉片；新动词是精准处决肉片立即赎回对应属性，过量伤害会把肉汁溅给猎杀者的下一次穿刺；公开反制为肉片归属、精准生命区间与溅射去向。 |
| H05 | **寄席胧光怪**。继承会复归的幻象，但幻象先附着到一名邻居并弱化复制宿主下一招；新动词是用预告的伤害形状把幻象从宿主剥到空槽，再在其重新附着前处理；公开反制为宿主连线、复制招式与剥离条件。 | **余辉胧光怪**。继承幻象死亡后归来的特征；新动词是在幻象死后的一整个玩家窗口内处置“余辉尸体”，玩家封印可取消一次复活，胧光怪先消费则按尸体保留的招式复生；公开反制为尸体倒计时、双方可消费图标和复生 Intent。 |
| H06 | **拼碗虫**。继承卵、蜜、石、丝四形态，将其拆成可独立击打的碗片并置于相邻槽位；新动词是移动或打碎碗片，主动决定哪两片邻接融合为混合招式；公开反制为融合连线、四套配方和拆片后的 Intent。 | **巡味盛碗虫**。继承四形态轮换；新动词是用左击、右击改变轮换方向，并在不重复形态的前提下依次“上齐四味”使其满足离场而非全灭；公开反制为形态环、下一形态与捕获奖励，断序只转入强化战斗而不立即判负。 |
| H07 | **巡巢虱祖**。继承首击蜷身与护巢倾向；新动词是从远离巢穴的一侧命中，把它推向相邻槽并改变蛛网、猛扑所覆盖的单位，借路线让猛扑撞上盟友；公开反制为巢位、推行箭头和区域 Intent。 | **遗壳虱祖**。继承蜷身，蜷起后会在原槽留下可保留一回合的空壳尸体；新动词是保壳让其挡住下一次猛扑，或精确拆壳换取战后材料，虱祖若先抵达则吞壳孵出幼虱；公开反制为行进路线、尸体时限与三方结果。 |
| H08 | **梦行甲虫**。继承覆甲沉睡和醒后滚动；新动词是用低于醒阈的轻击把它沿梦境箭头挪一格，诱导它在减速区醒来或撞向敌方槽位；公开反制为剩余唤醒值、落点区域和醒后滚动路径。 | **轮值熟睡甲虫**。继承“命中积累直至苏醒”，但每次有效命中把梦钥交给出手玩家；新动词是由另一名玩家承接下一击以消除一次唤醒进度，同一玩家连击则加速苏醒，单人按单段与多段交替降级；公开反制为梦钥持有者和预估醒来回合。 |
| H09 | **传赃草蜢**。继承偷牌、追赃与逃跑；新动词是攻击携赃者的左侧或右侧，把被盗牌在相邻敌人间转移，玩家可将赃物逼向无法逃跑的内侧再定点击杀；公开反制为赃物连线、下一传递方向和各槽逃跑出口。 | **赎票草蜢**。继承偷窃与撤退交易；新动词是在其每次振翅前支付公开的能量或金币赎回一张牌，赎回会延迟逃跑并开放下一件赃物，直接攻击则关闭谈判；公开反制为逐件价格、剩余回合和立即结算奖励。 |
| H10 | **寄甲外骨骼虫**。继承硬壳与槽位错相，甲片脱落后作为一回合尸体存在；新动词是先毁掉特定甲片，阻止相邻虫体捡起并继承其重击或多段模块，或故意留下错误模块污染其招式；公开反制为拾取箭头、模块招式与合成公式。 | **穿甲外骨骼虫**。继承单次伤害上限与队列站位；新动词是制造超过公开上限的伤害，将溢出部分沿直线传给它身后的单位，玩家可先调整队列再用重击借甲穿透；公开反制为本次上限、溢出数值和明确的承伤目标。 |
| H11 | **迁囊异螨**。继承施毒与吮吸，把毒囊附着在相邻宿主而非塞入解题牌；新动词是以轻击剥离、以重击刺破或推动宿主来改变毒液落点，使毒液伤到敌方队列；公开反制为宿主连线、剥离区间和破囊溅射范围。 | **换血异螨**。继承吮吸并给被咬玩家留下可见血滴；新动词是由另一名玩家命中异螨把血滴引回并治疗原目标，同一玩家追击则让异螨把血滴转成成长，单人按两种伤害形状交替；公开反制为血滴归属、可接力玩家和两种结算值。 |
| H12 | **排巢产卵虫**。继承产卵倒计时；新动词是从左右击打卵使其在槽位间滚动，同阶段相邻卵会预告融合成大型幼体，隔离的卵只孵化弱小职责单位；公开反制为孵化时钟、移动箭头和邻接配方。 | **温孵产卵虫**。继承结实卵与孵化；新动词是把每颗卵打进公开的“未裂、温裂、粉碎”三区间，温裂会孵出可捕获幼体，粉碎的过量伤害则溅射并催熟邻卵；公开反制为当前区间、连锁预览和捕获奖励。 |
| H13 | **食节千足虫**。继承体节接续复活，但死亡体节先作为一回合尸体保留；新动词是封印尸体阻止邻段吞食，或故意让指定邻段吞下并继承死者的一招以集中弱点；公开反制为吞食箭头、可继承招式和尸体时限。 | **编队千足虫**。继承多个独立体节与接续关系；新动词是在精确伤害区间内把命中的体节与相邻体节换位，先重排攻击、守护和复生职责，再处决暴露的首尾段；公开反制为换位区间、职责图标和重排后的全队 Intent。 |
| H14 | **接蜂术士**。继承“受到攻击便聚蜂”与高段蜂群，但蜂群标记附着于出手玩家；新动词是让另一名玩家用防御牌接走蜂群并把段数转成全队格挡，同一玩家继续攻击则喂大蜂群，单人按攻防交替；公开反制为蜂群持有者、可接动作和下一次段数。 | **蜂房术士**。继承召蜂与多段，将蜂房拆为能在槽位上移动的六角巢格；新动词是击打巢格改变邻接，闭环会强化术士，断开的直线则让蜂群沿线误伤敌人；公开反制为巢格连线、闭环判定和飞行路径。 |
| H15 | **折光棱柱**。继承污染射线与四拍循环；新动词是在标示伤害区间内旋转棱柱，让下一束射线沿槽位折射到敌人、空位或玩家，而非继续封锁牌类；公开反制为入射方向、旋转结果和完整光路。 | **接频棱柱**。继承攻击、技能、能力三类频率；新动词是让玩家 A 打出起始频率、玩家 B 接上公开的下一频率来令棱柱短路，重复玩家只会折返污染，单人改为连续不同牌型；公开反制为频谱队列、当前接棒者和短路回合。 |
| H16 | **轮舵帝皇蟹**。继承朝向、背击与多部件；新动词是命中舵爪的不同侧面，选择整只蟹顺时针或逆时针轮换槽位，把碾碎爪、火箭和背部暴露给不同目标；公开反制为轮换箭头、背击高亮和同步刷新的部件 Intent。 | **拾骸帝皇蟹**。继承部件死亡改变本体招式，但死爪先留下可争夺的一回合残骸；新动词是摧毁残骸取消该模块、保留残骸诱使核心花一回合安装，或精准拆解换奖励；公开反制为安装倒计时、继承招式与拆解区间。 |
| H17 | **沙脊无厌沙虫**。继承沙坑倒计时和地下突袭；新动词是对露出的不同脊段制造过量伤害，把沙坑标记沿场地推移，并将下一次突袭导向标记所在槽位；公开反制为脊段溢出阈值、沙坑路径和突袭区域。 | **赎路无厌沙虫**。继承限时逃生，却改成多人共同开掘的替代胜利契约；新动词是各玩家依次投入不同牌型推进路线，单人使用不重复序列，达标可驱离沙虫并保留未耗尽资源，断序则转入常规二阶段；公开反制为路线配方、剩余轮次和两套奖励。 |
| H18 | **传知恶魔**。继承知识诅咒选择；新动词是让知识印记在玩家间传递，非持有者回答下一次知识选择可封印一招，持有者连续作答则让恶魔合并两条诅咒，单人按不同牌型交替；公开反制为印记持有者、选项去向和被封印 Intent。 | **注疏知识恶魔**。继承每次选择都会扩张其知识库，将选项凝成相邻的“注疏”模块；新动词是击打注疏使其换位，重排三枚注疏后主动决定恶魔下一条组合定理；公开反制为模块词条、排列公式和组合招式预览。 |
| G01 | **引雷电球头**。继承流电、多段和成长，但电弧总是连向最近槽位；新动词是在精确伤害区间内旋转弧端，把下一次放电导向其他敌人或空槽，过量则越过导体命中玩家；公开反制为弧线、旋转区间和完整放电路径。 | **递电电球头**。继承能量侵蚀，将电荷附着于本轮最后花费能量的玩家；新动词是由另一玩家首次命中来把电荷泄入电球头并打断成长，同一玩家命中则形成回路，单人按花费能量奇偶降级；公开反制为带电玩家、可泄电动作与回路结果。 |
| G02 | **残垒炮手**。继承炮手与活体盾的配合；新动词是在活体盾死亡后的一回合内处理其尸体，炮手先回收会把它装成穿甲炮，玩家精准击碎则让残片反伤炮手；公开反制为回收路线、尸体区间和装炮后的射击公式。 | **交火炮手**。继承十连射与遮挡，把校射线锁在一名玩家身上；新动词是由另一名玩家命中活体盾，把校射线转接给盾后方单位并改写十发落点，单人以单体和群体攻击交替；公开反制为锁定线、可转接对象和逐发落点。 |
| G03 | **遗轴巨斧**。继承库存复生与巨斧招式，每具机体死亡后把斧轴作为一回合残骸留下；新动词是先拆轴让下一库存以徒手弱体复生，或留下轴诱使其花一回合拾取并继承上一具的招式；公开反制为拾取倒计时和复生 Move 预览。 | **错模巨斧**。继承库存替换；新动词是用致命伤害的纹理塑造下一具库存，精准单击生成盾斧体、多段生成锯斧体、过量伤害生成迟缓重锤体；公开反制为致命前的三种轮廓预览和当前伤害归类。 |
| G04 | **席位法官**。继承审查、证据与裁决，将三块证据牌置于可换位槽位；新动词是攻击牌座而不销毁证据，重排证据与法官的邻接关系，把裁决目标导向场上单位；公开反制为证据权重、席位箭头和裁决线路。 | **陪审法官**。继承三类牌的审查；新动词是由不同玩家依次提交攻击、技能或能力形成陪审顺序，互不重复的意见会减刑并改写裁决，同一玩家垄断则加重，单人按三类序列；公开反制为已提交序列、下一席玩家与裁决档位。 |
| G05 | **余料雕刻师**。继承仪式成长与雕刻，每次受击会掉落带本次伤害形状的石屑尸体；新动词是抢先把石屑精准雕成一次性工具，放任则由雕刻师消费并把对应攻击模块刻进自身；公开反制为尸体时限、可得工具和敌方继承招式。 | **邻像雕刻师**。继承制造活像，但雕像的左右邻接会拼成守护、追击或祭仪组合；新动词是击打基座移动活像而非只清场，刻意拆开强组合或拼出会误伤雕刻师的阵型；公开反制为移动箭头、邻接配方和组合 Intent。 |
| G06 | **跳格蛙骑**。继承覆甲与半血冲锋；新动词是在公开伤害区间内决定它跳一格还是两格，把冲锋线导向其他敌人，过量伤害则使其越过目标直扑玩家；公开反制为落点箭头、区间和完整冲锋路径。 | **缴枪蛙骑**。继承半血转折，在阈值处把长枪抛成可攻击模块；新动词是在精准区间内缴获长枪达成捕获式胜利并获得额外战利品，未处理则被骑士回收并强化冲锋；公开反制为回收时钟、缴获区间和两种结束奖励。 |
| G07 | **溢胶狂战士**。继承黏液与多段攻击，但黏液先成为占据相邻槽位的胶池；新动词是制造超过胶池容量的过量伤害，让溢胶推动狂战士并把伤害导向后方单位；公开反制为容量、移动方向和溢出承伤者。 | **牵胶狂战士**。继承黏液缠身，将胶绳系到最后攻击它的玩家；新动词是让另一玩家攻击来横向拉断胶绳并跳过一次连击，同一玩家追击会缩短胶绳并增强扑击，单人按远近伤害区间交替；公开反制为胶绳持有者、长度和下一结算。 |
