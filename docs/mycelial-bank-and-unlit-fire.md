# 深处事件与保守选项 · 1.22.0

本次加入第 5 个事件「菌根借贷所」和第 6 个事件「还没烧起来的火」，并按用户的新原则，将自制深处事件的无收益离开改为小额纯增益选择。

## 洞胃与既有事件

洞胃现在同屏显示攻击、技能、能力、诅咒四种喂食，以及「收下小费」；不再有「离开」或「拿出其他牌」的中间页。喂食奖励仍为攻击药水、50 金币、预先展示的罕见遗物、除咒后战斗。

下列保守选择统一获得 15 金币，金额集中于 `DepthsEventDefaults.SmallGold`：

| 事件 | 保守选择 |
| --- | --- |
| 礼貌的洞胃 | 收下小费 |
| 影子寄存处 | 认领零钱 |
| 收音井 | 捡起井边的金币 |
| 对齐之屋 | 从蓝屋的后门走，领取门后的零钱 |
| 菌根借贷所 | 收下赠礼 |
| 还没烧起来的火 | 拨开灰烬，拾取金币 |

已有结算之后的继续、结束流程不重复发钱。原版事件的选择不在本次修改范围内。今后自制事件的规则记录在 [事件设计规范](event-design-guidelines.md)。旧的本地化键保留给历史记录，当前可用选项目录过滤掉过时分支。

## 菌根借贷所

| 选择 | 立即代价 | 后续返还 |
| --- | --- | --- |
| 存短期 | 失去 12 生命 | 接下来三场战斗结束，各回复 6 生命 |
| 存长期 | 失去 6 最大生命 | 击败本章 Boss 后获得 12 最大生命 |
| 收下赠礼 | 无 | 立即获得 15 金币 |

短期要求当前生命大于 12，长期要求最大生命大于 6；该局已持「菌根存单」时不能重复存款。每名玩家独立选择，存单使用原生 Event 遗物与 SavedProperty 保存期限、所属章节和剩余次数。

短期只在拥有者存活时付款，满生命也会消耗该次返还；回复遵循原版修正。长期使用 `AfterCombatVictory` 的 Boss 胜利钩子，仅支付一次。若多人中本人死亡、队友打赢 Boss，欠款保留，直到本人在下一章存活进入房间时归还。跨章兜底也避免章节跳转使本金永久消失。

生命代价用原版事件伤害命令，最大生命代价与返还用原版 `LoseMaxHp` / `GainMaxHp`；后者按原版规则同时回复增加的最大生命量。短期基础总回复 18，长期净增 6 最大生命；数值尚未实战调校。

瘦蘑菇记账、胖蘑菇保管红色生命种子，两者用根相连。叙述与结果沿用具体动作和短对白。

## 还没烧起来的火

| 选择 | 效果 |
| --- | --- |
| 借一点温暖 | 立即执行原版休息，预支下一处地图休息点的机会 |
| 借一点火候 | 立即执行原版锻造，预支下一处地图休息点的机会 |
| 添些柴火 | 支付 25 金币，抵达下一处地图休息点额外回复 12 生命，并保留正常行动 |
| 拨开灰烬 | 获得 15 金币 |

休息量沿用原版最大生命 30% 与休息修正，使用 `PlayerCmd.MimicRestSiteHeal`；锻造使用原版 `SmithRestSiteOption`，保留可取消选牌、锻造数量修正与后续钩子。原生休息选项只生成一次，尊重其他遗物移除选项或调整锻造数量的效果；取消锻造不会建立预支约定。

### 未来火堆与多人

「余烬约定」按玩家持有，个人选择不会改变其他队友的休息机会。预支与添柴只能选一次；已有约定时可以选择小收益。

- 用原版地图任务标记显示各条可达路线上的第一处未访问火堆；路径改变或进入新章节后更新。
- 最终结算对象是实际到达的下一处地图火堆，不会被事件内的模拟休息提前消耗。绕过某一条路线并不能清除约定，剩余约定可跨章。
- 预支者到达时，自己的火堆画面熄灭，人物熄光；选项只剩「余烬已尽」，没有额外效果，点击后正常继续。
- 原生休息点同步器需要一个成功选择来完成房间。不能直接清空初始选项，否则其多人完成任务可能一直等待。因此保留原生协议内的单个无收益继续选项，由同步器完成退出。
- 使用针对 `RestSiteOption.Generate` 的窄后置补丁，在全部原生选项修改之后应用已预支的限制，防止铲子、修补等额外选项绕过代价；普通休息点不受影响。
- 保存火堆章节与坐标，已兑现的同一处火堆重建时仍视为用过，避免读档重新拿到行动。结算标记和模式均为原生遗物 SavedProperty。
- 添柴收益在到达时支付一次；本人死亡时不借此复活，收益仍算已使用。原生休息、锻造及额外行动继续可用。
- v107.1 显式登记新存档属性并更新网络属性编号位宽；v111 使用原生模型扫描。

火堆文案以「木柴没烧，灰烬却是热的」「昨日开放」和逆行的沙漏表达预支。事件中的休息数值实时计算，离线预览中的 24 生命仅是 80 最大生命的示例。
