# 事件插画与渐暗背景

后续自制事件沿用用户在 2026-10-05 最后明确的要求：「从画面中心逐渐淡出，周边依旧有画面，但是不是主体，且慢慢变黑」。

## 构图

- 主体集中在可用画区中部约 2/3；这规定视觉重心，周边仍保留完整场景的延伸。
- 从主体附近开始连续降低亮度和视觉权重，外围仍能辨认次要天空、地面、建筑等，经过较长距离才融入黑色。
- 用覆盖完整场景的明暗渐变组织画面，避免围绕主体描出固定轮廓、椭圆开窗、羽化剪影或短距离黑边。这些处理即使模糊边缘，也会产生用户明确不要的相框感。
- 插画重心位于左侧；靠近右侧原生文字与选项时逐渐压暗，允许暗部景物自然延伸到文字区。
- 主体保持清晰、明亮，外围通过降低亮度退后；保持景物纹理与形体清晰。维持 STS2 插画的大块明暗、简化轮廓与节制细节。
- 原生肖像会超出视口，按实际可见画区安排留白。不要仅凭 3440 × 1616 文件中的像素占比判断游戏里的构图。

## 制作与交付

1. 对照当前版本原版事件图与 `default_event_layout.tscn`，确定可见画区及文字位置。
2. 保留未裁切原画、独立明暗渐变遮罩和最终肖像。对齐之屋的合成示例是 `scripts/aligned_houses_composite.py`。
3. 查看插画本身和中英文排版预览，确认暗部仍有连贯景物、从中心到外围逐渐变暗、没有开窗轮廓、关键主体完整、文字和选项清晰。
4. 修改不符合以上条件的部分后再次查看最终图。说明预览是离线合成还是实际游戏截图；游戏验证遵从当次用户授权。

当前示例及源文件索引见 [对齐之屋](reality-aligned-houses.md)。
