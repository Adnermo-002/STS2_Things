# 怪物衍生创新扩展：密林与暗港

基线：[怪物衍生设计图谱](MONSTER_DERIVATIVE_ATLAS_V109.md) 的 J01-J22、D01-D21。主图谱为路线 A；本文为每个页面补充路线 B/C。每条都保留一个可辨认的原型机制，同时另开玩家动词、目标顺序或资源转换轴。

灵魂异鱼的三条简案之外，另有独立的 [灵魂异鱼籽家族创新设计](SOUL_ROE_FAMILY_DESIGN_V109.md)，包含十二个物种方向与组合遭遇。

## 密林 J01-J22

| ID | 路线 | 衍生名 | 继承的原型 DNA | 新规则 | 玩家主动反制 |
|---|---:|---|---|---|---|
| J01 | B | **孢盘飞蝇菌** | 易伤孢子、脆弱孢子和攻击轮换 | 三种行动排成可见孢盘；打出攻击使孢盘顺转，技能使其逆转，能力会钉住当前格，敌方行动时释放指针所指招式。 | 先看手牌能否用低代价牌转盘，把危险减益改道成攻击或较易承受的另一种孢子。 |
| J01 | C | **双囊飞蝇菌** | 两类减益孢子有独立身份，间以攻击穿插 | 易伤囊和脆弱囊各是一枚会再生的外置部件；对应孢子意图亮起时该囊暴露，摧毁它会取消这次减益并让菌子改用一次基础攻击。 | 根据当前防御与牌组，集中处理本回合最致命的囊；也可保留较轻的减益，把输出留给本体。 |
| J02 | B | **换岗劫掠队** | 多职业成员各有成长、重击、装填、追猎等专属招式 | 每轮结束，职业徽记沿队列轮换到下一具身体，生命与减益留在原身体；本回合被命中的成员会把徽记钉住一轮。所有轮换箭头提前显示。 | 用小攻击钉住即将转移的危险职业，再击杀承载关键徽记的低生命成员；也可放任辅助职业换到前排。 |
| J02 | C | **缴械劫掠队** | 职业强招依赖斧、弩、追猎索等军械 | 每件军械都是成员身旁的可见令牌；击破持有者当回合格挡会把军械震到中立槽，失械者下一轮只能徒手，另一名劫掠者会花行动去捡。 | 在强招前打空对应成员的格挡，连续把武器留在地上，或诱使最远成员浪费一轮拾取。 |
| J03 | B | **疤眼雾菇** | 利齿之眼会满血复活，死亡与雾菇召唤相连 | 击杀眼睛的最后一次攻击纹理会给下一次复活留下疤型：单次重击变成护卫眼，多次命中变成速咬眼，非攻击伤害变成孢疗眼；下一形态始终预告。 | 在眼睛残血时换用合适的收尾方式，把下一轮塑造成自己牌组最容易处理的职责。 |
| J03 | C | **漂瞳雾菇** | 眼睛复活时向牌堆塞入晕眩 | 眼睛归零后钻进一张带瞳标记的晕眩而非立即复活；该牌再次被抽到时眼睛满血出场，若玩家在回合结束前打出或消耗它，眼睛永久消亡。 | 追踪标记晕眩的位置，利用抽牌、检索、消耗或保留窗口完成“拔瞳”，再转火雾菇。 |
| J04 | B | **双牙蛮兽** | 易伤起手后交替重击与双击 | 重击牙和裂咬牙是两枚可击破獠牙；其对应意图亮起时獠牙暴露，断牙会移除该招的特殊效果并让蛮兽下轮花时间换牙。 | 在最难防的一招到来前打断对应獠牙；牌差不足时承受较轻招式并保留爆发。 |
| J04 | C | **试防蛮兽** | 易伤会放大后续重击或双击的威胁 | 施加易伤后进入一次公开“窥防”：玩家本轮若先获得格挡再造成伤害，它锁定双击；若先造成伤害再获得格挡，则锁定重击。锁定结果实时显示。 | 根据手里的无实体、荆棘、虚弱或格挡结构，主动安排攻防先后，把它导向更适合本回合防御的伤害纹理。 |
| J05 | B | **滤囊伏地虫** | 酸液小攻与一次大幅吸气强化 | 吸气会暂扣弃牌堆顶牌并显示在透明肺囊中；攻击、技能、能力分别让下一口酸液获得腐蚀、护膜或增生分支。肺囊在吸气回合可单独击破，破后原牌归还且强化失败。 | 在吸气前控制弃牌堆顶牌，喂给它最容易应对的分支；有输出时直接打破肺囊。 |
| J05 | C | **对流伏地虫** | 吸气蓄力后再以酸液释放 | 吸气时出现冷热双向气压计：攻击牌推向热端，技能牌推向冷端，能力把指针拉回一格；敌方行动时指针居中则呛气眩晕，偏向两端则释放不同的酸液招式。 | 计算本轮可用牌型，把气压调到中央；做不到时主动选择自己较能承受的端点，而非被随机招式命中。 |
| J06 | B | **双色墨宝** | 滑溜层将一次生命损失压到 1，之后交替单击与多段 | 滑溜层按“墨点、墨线”交错排列：单次攻击只能翻开墨点，多次命中只能翻开墨线；翻开的层需由另一种纹理命中才会溶解，顶层颜色完全公开。 | 交替使用单次和多段攻击两步剥层；缺少某种纹理时保留攻击，等待牌序完成配对。 |
| J06 | C | **借墨墨宝** | 被滑溜截断的高伤害不会直接降低生命 | 每次伤害被压到 1，溢出的部分转为公开墨池；墨宝行动时消费墨池改变单击和多段的拍法。攻击之后打出技能会吸走一格墨并转成临时格挡。 | 不把攻击一次性全打完，而在攻击与技能间穿插“吸墨”；也可用小攻击避免制造过多墨量。 |
| J07 | B | **三棱贾克斯果** | 每轮攻击并持续获得力量 | 果实有攻击、技能、能力三枚光面，每轮只点亮一面并从该面获得成长；在它行动前打出同类型牌会遮住该面，本轮不成长，下一面仍按固定次序点亮。 | 预留对应牌型作“遮光牌”；资源紧张时只压住即将配合多段攻击的关键光面。 |
| J07 | C | **摘芯贾克斯果** | 力量随攻击回合不断累积 | 每次成长不直接加在本体，而长成一枚带对应力量的果芯；果芯下一玩家回合可单独选取，若存活到敌方行动才并入本体并让攻击升级。 | 在果芯并入前摘除，永久删除那次成长；也可抢杀本体，或保留输出应付其他敌人而接受一轮并入。 |
| J08 | B | **换宿扼杀者** | 紧缠在扼杀者存活时持续结算 | 紧缠成为可转移的绳环：玩家回合最后被攻击的敌人会在回合末接住绳环；绳环在敌人身上时伤害该敌人但给扼杀者等量格挡，未转移时照常伤害玩家。 | 把最后一次小攻击落在最想削弱的敌人上借刀杀敌；需要打本体时先规划最后目标，避免绳环弹回自己。 |
| J08 | C | **反绞扼杀者** | 一次紧缠后进入攻防循环 | 身体分成头结与尾结两个可选部位；每轮首次命中头结会松一层紧缠但增强下一次咬击，首次命中尾结会让下一次紧缠反噬本体但使其获得格挡。 | 根据本轮防御和爆发选择松头或反绞尾，必要时两处都不碰以保留输出；结果在意图上即时重算。 |
| J09 | B | **弹页史莱姆（小）** | 冲撞与塞入黏液交替 | 冲撞会把抽牌堆顶牌弹到场上并公开，其位置由一片叶托住；在下一次敌方行动前打出一张相同费用的牌可接回它，否则被托牌变成黏液。 | 利用预览的费用保留一张“接球牌”，或提前操控牌堆顶，避免关键牌被同化。 |
| J09 | C | **折页史莱姆（小）** | 小型史莱姆以黏液干扰抽牌节奏 | 生成的折页黏液会夹住它后方一张牌并一起被抽出；打出黏液会立刻把夹牌送入手牌，丢弃黏液则把夹牌连同它压回抽牌堆底。夹住的牌始终可预览。 | 为关键牌支付黏液的费用以提前释放，或故意埋掉暂时无用的牌改善本轮手牌。 |
| J10 | B | **合团史莱姆（中）** | 固定的“双黏液、团块射击”两拍循环 | 每次生成的两张黏液带互补半印；两半在同一回合进入手牌时可合成一张可投掷团块，命中来源会取消下一次团块射击；若两半分处不同牌堆，循环时各复制一张。 | 用抽牌、保留和牌堆移动促成两半会合，及时把合团投回；也可在复制前消耗其中一半。 |
| J10 | C | **滚团史莱姆（中）** | 团块射击与黏液污染仍按固定周期到来 | 团块射击会在前方生成带方向的可攻击滚团；每次命中把它沿敌方队列推一格，撞到怪物会造成伤害并使其失去行动，未在倒计时前推回则撞向玩家并裂成两张黏液。 | 用若干小攻击校准滚动距离，选择撞晕史莱姆本体或危险队友；无暇处理时预留格挡并接受污染。 |
| J11 | B | **反震史莱姆（小）** | 行为核心仍是每轮简单冲撞 | 冲撞若被完全格挡，树枝会反插本体，使它下轮获得格挡并改为两段攻击；若造成未格挡伤害，树枝留在玩家身上，使下一张攻击临时加费，但本体下轮不防御。 | 主动选择全挡以换取可预测的双击，或漏少量伤害换取无格挡击杀窗；两种结果都提前显示。 |
| J11 | C | **弹枝史莱姆（小）** | 不断冲撞的轻型身体与富有弹性的树枝 | 每次冲撞后进入弹枝态；下一玩家回合首次命中会把它推向相邻槽，撞上盟友会同时伤害双方并取消下次冲撞，撞到边界则反弹并立即换向。 | 观察箭头，用低伤攻击把它推向高威胁敌人制造友伤，再把主输出落在真正目标上。 |
| J12 | B | **连枝史莱姆（中）** | 黏性射击限制手牌，随后以戳刺扑击惩罚 | 黏性射击会用藤丝连住两张公开手牌；只打出其中一张会自动丢弃另一张并强化扑击，连续打出两张则扯断藤丝并让扑击失去穿刺。 | 重新安排能量和出牌顺序，优先连续支付两张被连牌；代价过高时主动选择牺牲价值较低的一端。 |
| J12 | C | **树钉史莱姆（中）** | 重扑与黏性状态围绕“被枝条钉住”展开 | 戳刺会从弃牌堆顶钉走一张牌，作为本体前方的可击破护片；攻击牌护片赋予反伤，技能牌护片赋予格挡，能力牌护片赋予成长。护片破坏后原牌回到手牌。 | 在戳刺前控制弃牌堆顶，故意留下最容易应对的类型；下一轮优先破片取回关键牌。 |
| J13 | B | **等比甲虫** | 缩小会压低攻击伤害，之后啃咬与踩踏交替 | 缩小增加一条可见尺度链：本回合每张攻击的基础伤害严格高于上一张时，下一击恢复一级尺寸；相同则保持，变小则再次缩一级。每回合重置起点。 | 把低伤攻击放前、高伤攻击放后，先爬尺度再兑现爆发；不合适的攻击可留到下一轮。 |
| J13 | C | **尺壳甲虫** | 被缩小吞掉的攻击伤害不会完整落到本体 | 每次缩减的伤害会结成一片带存量的尺壳；尺壳可在下一轮单独击破，破坏后把存量加到玩家下一次攻击，若留下则在踩踏时化为额外冲击。 | 先用廉价攻击制造尺壳，再在大攻击前击破回收伤害；也可赶在踩踏前清空所有外壳。 |
| J14 | B | **编序蹒跚者** | 缠结提高攻击牌费用，之后双击与重咬施压 | 缠结不再作用于所有攻击，而把两张攻击用可见藤线连成一对；打出一端会令另一端再加费，在两端之间打出一张技能则剪断藤线并恢复原费。 | 先用技能断线再连打攻击；若能量不足，选择价值较低的一端弃置，避免二次加费。 |
| J14 | C | **储能蹒跚者** | 攻击牌的额外费用来自藤蔓勒紧 | 玩家为缠结多支付的能量会进入公开“绷力”池；下一张技能可消耗全部绷力变为 0 费，并按消耗量撕伤藤蔓。若回合结束未兑现，蹒跚者吞掉绷力强化重咬。 | 有意识地先支付一张加费攻击，再用关键技能免费兑现；牌序不合适时少打攻击，拒绝给它储能。 |
| J15 | B | **逐击啃兽** | 前、中、后排或独处分别对应攻防、强化、重击 | 每累计受到第三个独立伤害实例，它就按箭头移动一槽并立即重算下一意图；计数和目标槽始终可见，移动不带额外成长。 | 用多段或小攻击把它推到较安全的姿态，再以重击收尾；不想换招时避免触发第三次命中。 |
| J15 | C | **影位啃兽** | 啃兽会根据自己与同伴的相对位置选招 | 回合结束时它移动到本轮最后被玩家攻击的敌人身后，并借用该目标的“前排、后排或独处”身份决定招式；最后目标及落点有箭头预览。 | 把一张低伤攻击最后落在希望它追随的敌人上，诱导防御或强化姿态；击杀锚点可迫使它使用独处重击并暴露一轮。 |
| J16 | B | **折光方柱** | 覆甲、人工制品、蓄力炮击与最终排出 | 每次人工制品抵消减益都会让方柱棱面旋转一格，三个棱面分别把排出改成单发重炮、多段散射或附带减益；人工制品耗尽后棱面锁定。 | 在排出前用减益逐次转动棱面，停在最适合当前防御的炮型；也可保留减益，先打穿格挡。 |
| J16 | C | **中继方柱** | 长时间蓄力后一次性排出多段能量 | 蓄力时生成两枚占据空槽的中继晶体，排出光束会依次穿过它们；每枚晶体把单击拆成多段或把多段聚成重击，路径和最终意图完整预览。晶体破坏后光路自动缩短。 | 按自己的格挡、无实体或荆棘构筑，击碎对应晶体来选择最终伤害纹理；也可全拆换取一轮哑火。 |
| J17 | B | **迁域异鸟** | 领地意识持续成长，啄击与俯冲轮替 | 战场有三块可见领地，异鸟每轮宣告落点；首次命中会改变它的飞行方向，攻击宣告落点则破坏该地。它只有连续两轮落在未破领地才会成长。 | 用小攻击转向，再拆掉新落点，让它不断迁徙而无法积累领地；也可承受成长，把输出集中本体。 |
| J17 | C | **筑材异鸟** | 领地成长支撑啄击和俯冲 | 每次成长前会暂扣弃牌堆顶作为巢材：攻击材让下次啄击追加一段，技能材给俯冲护甲，能力材使领地多成长一次；摧毁巢材会归还原牌并取消效果。 | 在它筑材前控制弃牌堆顶，留下可承受的类型；下一轮打碎危险巢材取回牌。 |
