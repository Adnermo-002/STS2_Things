# 1.12.2 · 深处卡牌与能力描述

统一寄生、吸水体质、积水、冲净与致盲的中英文本，参照 v0.111.0 原版灼伤／感染状态牌、混乱、覆甲、再生与人工制品的本地化方式。

## 文案规则

- 关键词与能力名称使用 `[gold]`，能力说明中的数值使用 `[blue]`。取消怪物名称的红色和再生的绿色高亮。
- 卡牌数值继续使用原版 `diff()` 格式；固有、消耗由原版关键词系统显示。
- 寄生采用原版“在你的回合结束时，如果这张牌在你的手牌中……”句式，消耗后的反应另起一段。
- 致盲沿用原版混乱的“耗能”“随机变化”用词，直接说明抽牌数量、范围和持续时间。
- 吸水体质说明触发条件；积水说明喷淋效果；冲净说明消耗寄生的效果。动态描述明确显示当前层数。
- 英文沿用原版 `At the end of your turn`、`Hand`、`Exhausted`、`Regeneration` 等表达与大小写。

制作脚本中的文案已同步，后续重新准备资源会继续使用这些文本。战斗数值与结算逻辑沿用 1.12.1。
