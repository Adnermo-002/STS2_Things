# 评论区功能更新 · 2026-10-02

本次实现音乐开关、Boss/精英出现权重、仅模组 Boss 与指定 Boss。使用方式和完整键表见 [配置说明](CONFIGURATION.md)。

## 实现

- 关闭模组音乐后，六个 Boss 返回原版无自定义音乐标记；当前战斗停止模组曲目并恢复原版音乐，音效保留。再次开启时恢复 Boss 曲目和已缓存的阶段参数。
- 六个 Boss 与灵魂鱼子团精英提供 0–1000 的相对权重，默认 100。使用游戏原有种子随机数；默认配置保持原抽取操作。精英自定义正权重采用可重复抽样，并保留连续遭遇/标签限制。
- 强制和仅模组模式筛选实际 Boss 候选，已发现的 Boss 也能强制。自定义选项不会被发现顺序覆盖；没有可用模组 Boss 时回退，单候选时保留双 Boss 第二场。
- BaseLib、RitsuLib 和独立模式共用配置。保存格式兼容 BaseLib 的字符串字典，旧布尔/数值 JSON 自动迁移。修复 BaseLib 在保存前发出 Changed 导致状态滞后的问题，并兼容新版 RitsuLib 的独立 Settings 程序集。
- 为完成统一包构建，补齐活体巨岩在 V107.1 的伤害签名、碎晶调用、Spine 骨骼接口与轨道包装器生命周期适配；V111 仍按原范围释放包装器。
