# 深处第二章数值校准 · 1.25.2

> 后续玩家反馈上调过高，1.25.9 已整体回调自制普通怪与精英。当前数值见 [数值回调](depths-nerf-20261007.md)；本页保留当时的上调依据与历史验证。

深处普通战与三组自制精英的攻击、耐久和部分成长提高。重点是让实际攻击回合有第二章压力，同时保留原有控制次数、出场组合和可打断的蓄力。

本轮依据原版巢穴怪物源码和 v0.107.1 原生执行结果。原版弱遭遇已有偷窃跳虫 17／21 点攻击、掘地者 13／23 点攻击；岩石盛碗虫每击 15，猎杀者具有 7×3 连击。此前深处的鱼、蛾、水蛭多为 4–8 点，且防御／塞牌占据不少行动，未给其干扰机制配上足够的直接威胁。

人面柱仍是六层有限生命，初始显示三层，后备三层；不能将初始三层血量当作整个遭遇的总生命。余影魔仍保留伤害转为玩家格挡的解法，生命 999 不代表常规输出检查。

防御同步补足：灯鱼守势 9 → 12，水蛭蜷缩 6 → 8；海绵吸水格挡 6／8 → 10／12。爬岩初始壳 4／5 → 6／8、爬行壳 3／4 → 4／5；晶壳初始壳 6／8 → 8／10、缩壳 6／7 → 8／10；涎丝修壳 5／6 → 7／9。洞胃初始覆甲 10／12 → 12／14；人面柱封印格挡 5／6 → 7／9。

致盲仍影响下两张抽牌，牵丝仍捆两张牌，寄生仍每张给予存活血蛭两层再生和两层力量。涎丝、人面柱的虚弱仍一层。海绵的蓄水门槛与喷水回血仍各为最大生命的 10%；增加血量也相应增加了蓄水所需伤害。蜗牛的爬行回合数、破壳推迟和晶片奖励不变。洞胃吞食每张状态牌一力量、每餐上限三力量的规则不变。

双生子的基础护根格挡 10／12 → 14／16，并继续受丰盛／萎蔫形态修正；丰盛战孢 3 → 4 力量，萎蔫战孢 1 → 2。覆甲赠量、形态倍率、交换生命与同伴死亡时的四点力量不变。**实际意图含形态修正**：普通开场长兄根鞭为 22 点，不能把表中的 18 当作最终伤害。

蝾螈聚潮格挡 12／15 → 16／20，回流牌的减费与打出后给予蝾螈 2／3 力量保留。水母仍每三回合调频一次、收音每层增加两点；两张攻击牌的首轮最多三次攻击，从 21／24 → 27／30。只打技能会减少攻击次数并增加水母格挡，该对策仍可用。

原版精英未作全局替换。活体巨岩沿用已有第二章校准：其分阶段核心、反复断臂成本和抓取连招已形成显著压力，原有审查不支持与群怪一起统一加血，见 `docs/cavegod-act2-audit-20261005.md`。

## 同种子原生前后对照

固定种子，A0／A20、1／4 名玩家各测一次，覆盖八组弱战、十二组强战、三组自制精英及八组原版参照，共 124 条轨迹。角色不出牌、不击杀敌人、没有格挡，正常抽牌和回合结束钩子仍执行；故水蛭列**包含放任寄生的力量增长**。人面柱不减员，故不触发坍塌暂停；蜗牛不破壳，故碾压照常发生。水母没有玩家攻击／技能录音，轨迹只含末尾震波，其三击上限另列于上表。

这些是用于核对威胁预算的极端轨迹，不是胜率、玩家平均掉血或推荐承伤。敌人的击杀、破壳、移除寄生与调整出牌顺序会明显降低实际承伤。
