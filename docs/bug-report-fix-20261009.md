本机目录仍为 `user://mod_data/STS2_Things/bug_reports/`；`pending/` 保存待发送资料，`reports/` 保存完整本机副本及已确认发送的正文，`last-receipt.json` 保存最新回执。只在玩家主动选择琐事 F2 分类时联网。
