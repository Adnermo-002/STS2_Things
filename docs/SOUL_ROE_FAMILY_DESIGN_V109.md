## 设计目标

这份文档讨论“灵魂异鱼籽还可以进化成什么”，不是对现有实现做复盘。每条分支至少保留两个家族识别点，再改变一个战斗决策轴。

家族识别点：

1. **错相。** 个体处在防护、呼唤、攻击三拍中的不同位置。
2. **呼唤。** `Beckon` 既是延迟生命税，也是玩家可以主动支付的 1 费状态牌。
3. **孵化。** 死亡、倒计时和重组会改变场上单位数量。
4. **群体。** 八个固定槽位不是单纯容量，而是一圈可以表达相邻、方向和接力的拓扑。

设计时不把“再加一层无实体”“再多塞一张呼唤”“再生两只”当作创新。新的鱼籽应让玩家改变出牌顺序、攻击目标、击杀时机或保留状态牌的方式。

## 族群词典

为后续 UI、代码和讨论统一术语：

| 术语 | 规则含义 |
|---|---|
| 藏相 `Veil` | 防护拍。原型获得无实体；衍生种可以改为膜、换位或潜伏。 |
| 唤相 `Call` | 污染拍。原型生成呼唤；衍生种可以改变落点、所有权或用途。 |
| 噬相 `Bite` | 攻击拍。原型造成单次伤害；衍生种可以改成连击、回声或合击。 |
| 前进一相 | `藏 -> 唤 -> 噬 -> 藏`。 |
| 后退一相 | `藏 -> 噬 -> 唤 -> 藏`。 |
| 同相 | 两只鱼籽当前展示相同意图。 |
| 邻接 | 按 `soul_roe_1 ... soul_roe_8` 构成的环相邻，1 与 8 也相邻。 |
| 应答者 | 当前会响应玩家下一张呼唤的鱼籽；标记公开并按环传递。 |

## 核心创新一：把呼唤变成相位编辑器

### 规则

`Beckon` 仍保持原版身份：1 费状态牌，留在手中会在回合结束失去生命。新遭遇额外赋予它一个全局效果：

1. 场上最低顺位的活鱼籽开局获得“应答者”。
2. 任意玩家主动打出一张呼唤后，应答者的**当前意图**前进一相。
3. 应答者标记顺时针移动到下一只活鱼籽。
4. 连续打出多张呼唤会依次编辑不同个体；标记绕环后才会再次落到同一只。
5. 应答者死亡时，标记立即顺时针传递，不浪费玩家已规划的下一次编辑。

### 为什么成立

- 原本“花 1 能量避免 6 点生命损失”只有单牌权衡；现在它还能编辑敌方时间线。
- 玩家不能随意选择目标，因而仍需根据公开的环形游标提前规划。
- 多人中每位玩家都能推动同一个游标，产生协作而不需要额外选择界面。
- 呼唤没有被洗白成纯收益：把藏相推成唤相可能增加污染，把唤相推成噬相也可能立即提高伤害。

### 示例

```text
当前：1藏  2噬*  3噬  4唤     * = 应答者
打出第 1 张呼唤：2噬 -> 2藏，应答者移到 3
打出第 2 张呼唤：3噬 -> 3藏，应答者移到 4
结果：本轮少两次攻击，但下一轮会出现两只防护个体。
```

这不是“免费取消意图”，而是把当前伤害转换成后续防护或污染压力。

## 核心创新二：同相共鸣不是简单加数值

共鸣只检查**相邻**同相，避免六只鱼籽因为全局计数形成难读的连锁。每条共鸣边由顺时针靠后的个体担任“回声端”，意图旁显示第二枚小图标。

| 相位 | 原动作 | 共鸣回声 | 可见反制 |
|---|---|---|---|
| 藏相 | 获得个人防护 | 改为给全族群补 1 层共享膜；不额外叠无实体 | 先用小段数耗膜，或拆开共鸣边 |
| 唤相 | 生成呼唤 | 整条边额外生成 1 张呼唤，固定进入抽牌堆；不按成员数倍增 | 改相或击杀任一端 |
| 噬相 | 单次攻击 | 回声端把攻击改为两段、总基础伤害只小幅提高 | 格挡结构和减力量都能反制 |

重要限制：

- 一只鱼籽同一轮最多作为一条边的回声端。
- 三只连续同相只形成两条视觉边，但仅最前一条和最后一条交替激活，避免三倍增幅。
- 共鸣在玩家回合开始锁定；玩家改相后立即重新计算并刷新意图。
- 任何奖励都来自“改变攻击纹理或资源位置”，不靠隐藏伤害倍率。

## 核心创新三：镜相复制的是语义，不是对象

镜相鱼籽只复制鱼籽家族的三个语义相位，不直接克隆任意 `AbstractIntent`：

| 邻居相位 | 镜相动作 |
|---|---|
| 藏 | 获得 1 层共享膜，不获得无实体 |
| 唤 | 生成 1 张呼唤到弃牌堆 |
| 噬 | 造成邻居基础伤害的 50%，向上取整 |

复制目标按顺时针最近活单位确定，连线和来源槽位公开。来源在敌方行动前死亡时，镜相鱼籽进入一次眩晕；来源改相时，镜相意图立即改动。

这种设计保留“幻影复制”的惊喜，却避免两个常见问题：

- 不复制动态对象，减少意图、伤害来源和联机状态歧义。
- 玩家杀来源就能获得明确收益，不会出现意图图标仍显示旧动作的欺骗。

## 核心创新四：共享膜替代无实体海

### 共享膜规则

- `SoulMembranePower.Amount` 是全族共享的膜层数。
- 任意活鱼籽受到一次未格挡伤害时，若膜大于 0，该次生命损失最多为 1，并消耗 1 层膜。
- 完全格挡不消耗膜；同一攻击的每一段分别判断。
- 藏相鱼籽补膜，而不是各自获得持续一整个玩家回合的无实体。
- 新孵化鱼籽加入当前膜池，不重置也不额外复制层数。

### 决策变化

原本六只轮流无实体会让单次重击频繁浪费，且目标逐个维护防护。共享膜把问题改为“先用什么伤害纹理破公共资源”：

- 多段牌能快速剥膜，但会把低段数浪费在 1 点封顶上。
- 单体牌组可以先用零费或低伤害攻击开膜，再把重击交给真正目标。
- 群攻一次只对实际命中的每个个体消费对应层数，既强但不是直接跳过机制。

原版无实体仍可保留给母体或罕见个体，家族不会失去“虚化”视觉语义。

## 核心创新五：延迟孵化允许玩家塑形

`DormantSoulEgg` 以两回合倒计时和一个出生相位入场，卵壳颜色与意图同时预告出生结果。

### 玩家可以做三件事

1. **击破。** 卵有低生命，直接击杀永不孵化。
2. **延迟。** 主动打出呼唤使倒计时 +1，但全场每轮最多延迟一次。
3. **改相。** 同一张呼唤也会让应答卵前进一相，允许把即将攻击的卵改成藏相或唤相。

倒计时归零时，卵在原槽孵化，不额外眩晕，首招采用预告相位。若槽位被其他复活单位占用，卵保留在场并把孵化延后一轮，不静默丢失实体。

### 变体

- **早产卵：** 每次受到未格挡伤害倒计时 -1；高爆发会换来更早行动。
- **营养卵：** 玩家在卵期打出的攻击、技能、能力数量决定出生 caste。
- **空响卵：** 不孵化怪物，倒计时结束时把所有弃牌堆呼唤移到手牌；优先清状态可让它空爆。

## 核心创新六：死亡分裂的反向命题

逆生鱼母把“杀母体后出现鱼籽”反过来：放任鱼籽保持正确阵型，会重新组成母体。

### 胚环判定

- 三个连续活槽位按顺时针呈 `藏 -> 唤 -> 噬` 时形成胚环。
- 玩家回合开始时给三者加连线与一回合倒计时。
- 下一敌方回合开始仍满足条件，则三者退出战斗，在中间槽生成 `ReverseSoulBrood`。
- 融合生命为三者当前生命总和加固定壳值，不读取最大生命，避免故意把残血单位变成满血母体。
- 共享膜、力量和倒计时只继承白名单字段；负面状态按最高层继承一次，不复制三份。

### 小母体招式

小母体只运行三拍，顺序来自胚环：

1. **缝膜：** 获得等于融合成员数的膜。
2. **反呼：** 从每名玩家弃牌堆移除 1 张呼唤；每成功移除一张，下次攻击多一段。
3. **逆孵：** 攻击后重新裂成三只后退一相的鱼籽，均以当前生命比例出生。

玩家可以通过杀死一端、用应答者改相、或先让胚环成员分散到非连续槽位阻止融合。融合不是随机惩罚，而是提前一整轮公开的目标任务。

## 额外分支详案

### 反拍鱼籽：制造拍频

普通鱼籽前进，反拍鱼籽后退。两者每三回合重新相遇：

```text
普通：藏 -> 唤 -> 噬 -> 藏
反拍：藏 -> 噬 -> 唤 -> 藏
```

它不需要额外 Power，却能让玩家预测“本轮分散、下轮同相、再下轮交换职责”。适合普通遭遇或作为其他复杂怪物的简单搭档。

### 遗响鱼籽：把过量伤害变成资源

遗响生命为 1，只存在到下一敌方行动。它继承死亡时的意图，但数值减半。致命一击的过量伤害达到阈值时不生成遗响，因此高伤单体牌获得与群攻不同的优势；没有过量伤害时，玩家仍可用任意一次命中清理。

### 哑声与食声：改变呼唤的生命周期

- 哑声鱼籽把弃牌堆呼唤推向抽牌堆顶，是“时间压缩器”。清空来源状态会让它当场失去动作。
- 食声鱼籽吞弃牌堆呼唤，是“污染回收器”。它短期帮玩家减负，长期却把污染变成孵化资源。

两者同场时形成罕见但可读的生态：哑声负责搬运，食声负责消费。玩家可以主动打出呼唤切断整条食物链。

### 潮环鱼籽：把攻击变成布阵工具

潮环每个玩家回合只响应第一次命中：自身前进、逆时针邻居后退。触发前显示双向箭头。它让低伤害攻击承担“推棋子”的作用，但不会因为多段或群攻触发不可控连锁。

## 遭遇配方

单只衍生怪不应同时携带所有模块。以下配方各自只提出一个主问题。

### 普通：错拍幼群

```text
2 普通鱼籽 + 1 反拍鱼籽
```

- 教学目标：看懂正拍与反拍会周期性碰相。
- 不启用共鸣、不启用融合。
- 第一次碰相只改变意图纹理，不额外加高伤害。

### 普通：一呼一应

```text
2 应答鱼籽 + 1 潜孵鱼卵
```

- 开局给玩家弃牌堆放 1 张呼唤，确保机制可交互。
- 玩家决定用它改掉即将攻击的鱼籽，还是延迟卵。
- 同一张牌只触发应答者与应答卵中的当前标记者，不双重结算。

### 精英：合唱环

```text
4 共鸣鱼籽 + 2 织膜鱼籽
```

- 应答者标记沿六只鱼籽传递。
- 共鸣只按邻接，同相边一眼可数。
- 防护全部使用共享膜，不再叠个人无实体。
- 击杀顺序题：破共鸣边、清膜源、还是先杀当前噬相。

### 精英：镜潮育场

```text
1 镜相鱼籽 + 2 潮环鱼籽 + 2 潜孵鱼卵
```

- 镜相来源固定顺时针，潮环允许玩家重写其来源相位。
- 卵只承担倒计时，不再增加共鸣规则。
- 适合强调小攻击、目标顺序和未来意图，而不是纯 AoE 检查。

### Boss：逆生异鱼

阶段一：一只母体周期性产下普通、反拍与应答鱼籽。  
阶段二：母体首次死亡后不直接生成固定六只，而是留下三个预告胚环。  
阶段三：玩家若未拆环，胚环融合成逆生鱼母；若全部拆除，母体死亡结算完成。

Boss 的三个状态轴是：应答游标、共享膜、胚环倒计时。共鸣在此战禁用，避免第四套 UI。

## 最值得做的三个纵切

### P0：一呼一应

目标：证明“主动打出呼唤改变意图”本身有趣。

内容：

- `ResponderSoulRoe` 或现有鱼籽上的 `SoulResponderPower`。
- 一枚公开应答者标记。
- 呼唤结算后前进当前 `MoveState`，再移动标记。
- 只做三只鱼籽的小遭遇，不加入共鸣、膜和融合。

成功标准：玩家会为改相主动支付 1 能量，而且该选择不总是正确答案。

### P1：合唱环

目标：证明相位可以形成空间关系，而不是单纯三个计数桶。

内容：

- 邻接共鸣边。
- 共享膜取代衍生种的个人无实体。
- 改相后即时刷新意图与连线。
- 固定四只鱼籽，覆盖环首尾相邻。

成功标准：玩家会根据边而非只根据最低生命选择目标；多段与单次攻击都有用途。

### P2：逆生异鱼

目标：把孵化、相位和环形槽位整合成一个完整 Boss 阶段。

内容：

- 胚环识别与公开倒计时。
- 三实体退出、融合母体加入、白名单状态继承。
- 小母体再次裂分。
- AOE 同批死亡、满槽、存档、重连和多玩家目标验证。

成功标准：融合发生时玩家知道自己前一回合错过了什么，而不是感觉遭遇随机翻阶段。

## 实现形状

这部分只约束创意的可实现性，不决定最终代码结构。

### 建议类型

| 类型 | 职责 |
|---|---|
| `SoulRoePhase` enum | `Veil=0`、`Call=1`、`Bite=2`；所有入口严格归一到 0-2。 |
| `SoulRoePhaseRules` | 相位前进、后退、槽位顺逆时针排序、邻接和胚环纯函数。 |
| `ResponderSoulRoe` | 三相招式与运行时 `SetPhaseImmediate`。 |
| `SoulResponderPower` | 唯一应答游标；响应 `AfterCardPlayed` 中的 `Beckon`。 |
| `SoulResonancePower` | 计算当前激活边并提供回声；不保存重复缓存。 |
| `SoulMembranePower` | 共享伤害封顶与膜消耗。 |
| `DormantSoulEgg` | 倒计时、出生相位与同槽孵化。 |
| `ReverseSoulBroodPower` | 胚环倒计时、融合和战斗结束拦截。 |
| `ReverseSoulBrood` | 三拍小母体。 |

### 相位状态

- **出生相位**可以由 mutable 配置传入。
- **当前相位**以 `NextMove.Id` / 状态机当前状态为唯一事实；避免再维护一个会漂移的普通字段。
- 运行时改相使用该怪自己的固定 `MoveState` 并刷新意图。
- 应答游标、共享膜和融合倒计时使用可见 Power Amount 或明确的同步状态。
- 计算邻接、应答者和胚环时始终按数值槽位排序，不按集合迭代顺序。

### 原生落点

- 打出呼唤：`AfterCardPlayed(PlayerChoiceContext, CardPlay)`。
- 改当前意图：`MonsterModel.SetMoveImmediate(..., forceTransition: true)`。
- 伤害与伤害封顶：`DamageCmd` 及 Power damage hooks。
- 牌堆移动与生成：`CardPileCmd`。
- 孵化、融合和替换：`CreatureCmd.Add` 加死亡/倒计时 Power。
- 动态生成的所有怪物、Power、意图和视觉由召唤者 `AssetPaths` 预加载。

## UI 与美术语义

玩家必须在不读长 tooltip 的情况下分辨机制：

| 信息 | 表现 |
|---|---|
| 当前相位 | 卵核三种固定符号，不只靠颜色：闭眼 / 涟漪 / 牙。 |
| 正拍或反拍 | 核外顺时针或逆时针小箭头。 |
| 应答者 | 单一高亮环与下一目标的细箭头。 |
| 共鸣 | 两只相邻鱼籽之间的脉冲线，回声端更亮。 |
| 共享膜 | 一条跨鱼群的膜计数，不给每只重复挂同样图标。 |
| 镜相来源 | 单向细线，来源死亡时立即断裂。 |
| 胚环 | 三角膜与 `1` 回合倒计时，融合产物剪影提前显示。 |

贴图变体不能继续只表达“出生时是哪一相”却永远不随行动变化。若暂时沿用静态整图，至少把相位、方向和连线交给独立 VFX 层表达。

## 平衡护栏

1. 普通遭遇最多启用一个全局规则：应答、共鸣、膜或融合四选一。
2. 精英最多启用两个，并确保两者共享同一信息源，例如“相位 + 邻接”。
3. 共享膜初始层数不超过活鱼籽数的一半；藏相只补固定量，不按成员数平方增长。
4. 共鸣奖励按边结算且有全局上限，避免六只同相产生六倍污染或伤害。
5. 主动打出呼唤每次只编辑一个目标，确保多张呼唤仍需真实能量投入。
6. 逆生融合以当前生命为基础，不免费治疗；状态只白名单继承。
7. 多人中每名玩家承受的状态和攻击不再额外按玩家数增长公共资源。
8. 意图改变、共鸣断裂、膜消耗和融合取消都要立即刷新可见状态。

## 明确舍弃的方向

- 只把鱼籽生命和伤害提高后命名为“强化鱼籽”。
- 给所有鱼籽永久无实体或每回合刷新多层无实体。
- 每只鱼籽各自维护一个共鸣、膜、孵化和愤怒计数器。
- 根据本地动画帧、贴图颜色或节点位置决定相位。
- 随机选择融合成员、镜相来源或应答目标，却不在上一轮公开。
- 让呼唤既触发玩家生命税又无条件强化所有鱼籽，导致主动打出永远是错误答案。

家族最有潜力的方向不是“更多鱼籽”，而是让鱼籽成为可被玩家编辑的敌方时间线。相位、邻接和呼唤一旦相互作用，同样三种基础动作就能产生截然不同的目标顺序与资源选择。
