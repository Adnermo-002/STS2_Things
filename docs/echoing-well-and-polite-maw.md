# 深处事件：收音井与礼貌的洞胃

基础功能在 1.21.0 加入。洞胃首页选项与文风的 1.21.1 修订见 [选项与文风调整](polite-maw-polish.md)。

两个事件加入深处普通事件池，均默认启用，分别提供本模组、BaseLib 与 RitsuLib 设置开关。未改变其他章节的事件池或既有洞胃战斗数值。

## 收音井

永久移除一张可移除的攻击或技能牌，获得事件遗物「瓶中回声」。接下来的三场战斗，玩家首回合抽牌完成后，获得该牌的一张 0 费、消耗、虚无的临时复制品。遗物显示剩余次数，并可悬浮查看封存的原牌。

普通能量 X 费、星星 X 费和原生不可打出的负费用牌不参与选择。原版 `SetToFreeThisCombat` 无法把 X 费改成真正的零消耗，所以明确在选项及选牌提示中标出「非X费」，没有为其重写一套付费规则。普通星星费用沿用原生免费接口降至零。

- 原牌的升级、附魔及 SavedProperties 使用 `SerializableCard` 保存。
- 复制品只注册到当前 CombatState，使用原生 `AddGeneratedCardToCombat` 加入手牌，不进入永久牌组。
- 首回合时机采用原版 `VexingPuzzlebox.AfterPlayerTurnStart`；手牌满时沿用原生移入弃牌堆规则。
- 每场最多生成一次；通过战斗实例区分同层内的不同战斗。仅玩家存活并实际获得复制品时消耗次数。
- `StoredCard` 和 `RemainingCombats` 跟随原生遗物存档。v107.1 注册 SavedProperty 兼容缓存，v111 使用模型扫描。
- 多人各自选择封存牌，分别持有遗物和剩余次数。该事件不共享选择。
- 最少留一张牌在永久牌组中；已领取过瓶中回声的玩家不能再次封存。

叙事从「石头落井，却先响起拔剑声」开始。两只幼年收音水母守着井口，玩家把一招的声音装入瓶中，原来的牌永远沉入井下。

## 礼貌的洞胃

| 喂食牌型 | 回礼或后果 |
| --- | --- |
| 攻击 | 移除一张攻击牌，领取一瓶原版攻击药水 |
| 技能 | 移除一张技能牌，获得 50 金币 |
| 能力 | 移除一张能力牌，获得菜单提前显示的一件罕见遗物 |
| 诅咒 | 移除一张可移除的诅咒，随后与一只馋嘴洞胃战斗 |

保留免费离开。首页直接提供攻击牌、技能牌、其他牌与离开四个选项；其他牌页面提供能力、诅咒与返回。使用原版字号与按钮尺寸，洞胃自身正文留白调整为 220，以容纳多人共享提示。

### 原生奖励和战斗

- 选牌使用原生 `CardSelectCmd.FromDeckForRemoval`。只有实际移除有效牌后才给予对应回礼；保留至少一张牌。
- 攻击药水通过 `RewardsCmd.OfferCustom` 和 `PotionReward` 领取，药水栏满时可在奖励界面处理原有药水，不直接吞掉回礼。
- 技能金币经过原生 `PlayerCmd.GainGold`，保留正常金币修正。
- 罕见遗物按原版 Wongo 展示商品方式，在事件开始时从原生遗物袋预留一次。能力分支显示本玩家将获得的具体遗物及悬浮说明；来回翻页不会重抽。耗尽该稀有度的遗物袋时使用原生后备遗物规则。
- 除咒后通过 `EnterCombatWithoutExitingEvent<CaveMawWeak>` 进入既有单洞胃遭遇，沿用其数值、背景、骨骼、人数缩放和正常战斗奖励，不额外赠送奖励。
- 进入战斗之前明确标红提示。该分支选牌不可取消，避免多人已经同意战斗后有客户端停留在另一个页面。

### 多人

这是原生共享事件：全队投票选择菜单和分支，然后每个存活玩家分别选择自己喂出的牌、领取自己的回礼。

- 攻击、技能、能力分支要求每个存活玩家均有对应可移除牌，确保每人都能完成交易；无任何全队可用交易且无人能除咒时，本事件不进入候选。
- 诅咒分支只需至少一人有可移除诅咒。有诅咒者各除一张，其他玩家同样参加战斗。
- 所有玩家的事件实例都会向原生 EventCombatSynchronizer 报告就绪，包括没有诅咒或已死亡的玩家；同步器等所有选牌结算完毕才统一切换房间。
- 战斗伤害与生命缩放使用既有洞胃实现。菜单使用原生共享投票、焦点、悬浮与选牌同步，不另建网络协议。

数值定位是带选择的正收益事件：技能换 50 金币，攻击换实用药水，能力换罕见遗物，需要权衡放弃的构筑价值；除咒以一场普通战斗作为代价。尚未经过实战胜率调校。

## 美术和文案

两张事件插画和「瓶中回声」图标使用用户指定的 `gpt-image-2.5-sunburst`，经 imagegen skill 官方 CLI 调用既有授权 API 生成。收音井参考原版「深渊浴场」的画法与现有收音水母形象；洞胃插画参考原版「水淹抄经室」画法与现有洞胃形象。

画面保留大块明暗、略带卡通的生物比例和节制纹理。完整环境由中心向四周慢慢变暗，周边仍有岩壁、台阶、流水和菌光，没有围绕主体裁出黑色开窗。
