# 始源雾菇动作调整 · 1.10.7

此文记录 1.10.7 的历史实现。当前 1.10.8 的大幅动作、跨步与跃起方案见 [始源雾菇动作表现](origin-fogmog-impact-20261003.md)。

表现方向改为沉重、扎根的菌木 Boss：双脚稳定承重，身体先发力，宽菌盖延后回摆，召唤与恢复通过吸气膨胀和孢子释放表现。原画、骨架和修复过的蒙皮保留。

## 动作

- 待机：缓慢呼吸、微小重心变化与不等间隔眨眼，手臂轻微跟随；不再用大幅来回摆动表现呼吸。
- 挥爪：收肩蓄力后向前抓挠，前爪保持平衡，菌盖带有惯性。
- 头槌：独立 `headbutt`，用菌盖与躯干前压攻击，改用钝击特效。
- 三连击：独立 `triple_attack`，在低重心姿态下连出三道不同高度的抓挠，保持一次原生多段攻击命令。
- 召唤、施法、恢复：站稳吸气后释放孢子，手臂随胸腔张开，取消原先召唤时的大幅跳跃。
- 受击：短促躯干后缩、菌盖迟滞回弹；原有坐倒枯萎和复苏动作保留。

挥爪接触为 0.64 秒，头槌为 0.80 秒，连击为 0.48 / 0.94 / 1.40 秒。模型使用动画绝对时间对齐伤害与命中特效，快速和即时模式同样提交接触姿态。攻击仍经过原生 `AttackCommand`，保留伤害、力量、格挡、目标选择和多段攻击 Hook 语义。

原有特效骨骼位于身体外侧约 600 多个骨骼单位。现在尘雾发射点位于双脚之间，孢子发射点位于菌盖，并将高速向下喷射改为缓慢上浮的孢子。受击或切换动作会停止继续发射。

## 可重建与验证

`tools/OriginFogmogRig/v3/motion.mjs` 在原蒙皮修复之后生成动作层，`rebuild.ps1 -Deploy` 会同时生成并检查蒙皮和动作，再部署工程资源。原始输入继续保存在 `v3/source/`。

```powershell
.\tools\OriginFogmogRig\rebuild.ps1 -Deploy
.\scripts\test-origin-fogmog-actions.ps1
.\scripts\test-origin-fogmog-actions.ps1 -Preview
```

动作检查在原生 Spine 中对十段动画采样，共 2,640 个姿态；另检查脚部滑动、手臂伸缩、关节连续性及归位姿态。战斗时序检查共用既有原版战斗测试宿主，覆盖 1/2/4 人、普通/快速/即时模式和四种攻击招式，共 36 种组合，同时检查单次多段攻击、实际伤害、孢子方向和打断清理。

证据与预览位于 `build/origin-fogmog-motion-20261003/`。真实网络联机未进行人工实战验证。

## 检查结果

- 蒙皮接缝：2,640 个姿态，九处接缝均通过；爪根错位小于 0.001 单位，脚踝最大错位 0.473 单位。
- 新动作中的双脚位置漂移小于 0.0004 单位；关键关节最大单帧移动为 3.384 单位（120 Hz），所有动作回到待机姿态。
- 138 帧初版几何渲染未出现达到检测阈值的脱落碎片；最终原生场景另输出 30 FPS 连续画面，包含实际孢子效果。
- 36 种招式/人数/速度组合通过原版命令检查：实际伤害、攻击次数与命中姿态正确，三连击仍为一次多段攻击；孢子向上飘散，打断后停止发射。
- 可重建流程通过，重建 JSON 与最终工程资源哈希相同；V107.1/V111 编译、统一包加载及源码/PCK 审计通过。
