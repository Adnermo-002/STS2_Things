# 1.13.4 · 再寄生插入回合与手牌生成

寄生被消耗时仍保留水蛭当前回合的意图。当前行动执行后，在下一回合插入一次再寄生，并保存该水蛭原本下一步的行动。插入结束后接回保存的行动，不再固定跳回再啜。普通行动循环仍是啜血 → 寄生 → 再啜 → 盘伏，插入行动不推进或重置这个循环。每只水蛭独立保存进度；同回合多次触发合并，连续插入也保留同一个续接点。眩晕按原版先完成，之后继续补牌及原定行动。

寄生删除固有，只保留消耗，仍为 1 费状态牌。按用户确认，保留每只水蛭开场给每名存活玩家 1 张寄生的规则，直接加入手牌，再照常抽取 5 张起手牌。纯弱战起手共 7 张，纯强战共 8 张，不扣正常抽牌数量。普通寄生与再寄生行动也直接加入手牌。使用原版生成牌与手牌上限处理，手满时进入弃牌堆；不会加入永久牌组。

直接加入手牌不是抽牌，因此不会消耗冲净层数；以后从牌堆抽到寄生时仍会正常触发冲净。留手给予再生与力量、消耗触发补牌，以及顽固寄生隐藏的规则保持不变。
