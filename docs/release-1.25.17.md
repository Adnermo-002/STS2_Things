# 尖塔：琐事 1.25.17

启动公告改为轻松的邀请：遇到模组 Bug，可以按 F2 选择「琐事 Bug（上传本局）」，简单说说怎么回事就行。删去复现步骤、联机人数、其他模组和立即上报等要求，保留主动发送附带本局状态及失败重试说明。英文同步调整。

仍使用原版弹窗和按钮，每次启动显示一次。玩法、上报流程与其他内容沿用 1.25.16。

重新编译两版实现和统一引导，内嵌哈希核对通过；PCK 逐项核对 1308 个资源，仅两张公告本地化表改变。中文公告在独立 v107.1 客户端查看。此文案修改没有重复整套战斗测试。

## English

The startup notice now simply invites players to briefly describe what went wrong. Removed requests for reproduction steps, player counts, other mods and immediate reporting. F2 category and retry instructions remain. Gameplay and reporting behavior are unchanged from 1.25.16.

The unified package still supports v0.107.1 and v0.111.0. Both implementations and the bootstrap were rebuilt and verified; only the two localization tables changed in the resource pack.
