# 1.15.1：逆流蝾螈动作与怪物能力文案

本次细化逆流蝾螈骨骼动画，并精简全部 31 项自制怪物能力的中英文说明。数值、卡牌规则、行动顺序和命中时刻保持原有实现。

## 动作

- 50 根骨骼、11 个原画层、12 组动作。新增胸部、背部、后胯和三个尾鳍末端控制，沿用已有原画。
- 待机为 6 秒循环：胸腹呼吸、缓慢观察、错开眨眼、鳃叶和尾鳍跟随。
- 尾浪先下沉蓄力，后足支撑，前足依次抬起并落地；击中后分脚回位。
- 七段尾巴按时间差传递动作，三个尾鳍末端各自滞后收势，不再整条同步摆动。
- 倒卷的三次接触逐渐加重，中间有反向回摆；蓄流在攻击后收尾、压低身体防守。
- 回流与强化各有抬头、张鳃和身体舒展；受击快速后缩，再逐步复位。
- 倒地改为头部下垂、身体先落下、尾部随后停稳；腿根与躯干使用连续权重，减少动作中的接缝。
- 重做双眼下方的遮挡补图，避免眨眼时暴露由旧边缘填充复制出的深色鼻孔与眼圈拖影。

尾浪、逆潮、三连击和蓄流的结算仍分别对齐 0.50、0.56、0.46／0.74／1.02、0.56／1.20 秒。

## 能力文字

参考原版 `ENRAGE_POWER`、`RITUAL_POWER`、`CURL_UP_POWER` 等条目：触发条件在前，效果在后；数值使用蓝色，关键词使用金色；去除剧情感叹、实现术语和重复层数播报。

| 能力 | 修改后的主说明示例 |
| --- | --- |
| 断刃 | 本回合无法打出攻击牌。 |
| 护主 | 有盛碗虫存活时，受到的玩家攻击伤害减少 50%。 |
| 冲净 | 消耗接下来抽到的 {Amount} 张状态牌。 |
| 积水 | 达到 3 层时，下次行动改为喷淋，随后失去所有积水。 |
| 断根狂暴 | 攻击伤害提高 25%，保持丰盛，并使用狂暴招式。 |
| 逆流 | 玩家回合开始抽牌后，返还其上回合最后一张可回流的牌，本回合耗能少 1。每当玩家打出回流牌时，获得 {Amount} 点力量。 |

喷淋的四种减益减层与冲净效果、回流的选牌条件，通过原生 `HoverTip` 补充显示。菌根双生子保留生命交换、平血互换、丰盛／萎蔫效果、强化量和同伴死亡规则。牵丝在生效后说明解开条件，并明确所有垂丝蛾死亡时解除。

覆盖：芽孢爆发、鱼子爆发、死亡律动、缩小、放大、异鱼症、护巢本能、馈赠、晕眩打击、弱点探寻、护主、怪癖、振翅、消化、断刃、碎盾、刚猛试炼、坚韧试炼、封印、老化、晶脉、崩落裂痕、致盲、吸水体质、积水、冲净、顽固寄生、牵丝、同根、断根狂暴、逆流。

同时纠正了“消化”英文说明的旧数值：代码实际给予 1 力量，英文原先写为 2。内部同步能力继续隐藏，不改变水蛭顽固寄生的显示策略。
