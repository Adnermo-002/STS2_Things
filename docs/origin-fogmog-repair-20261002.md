# 始源雾菇蒙皮修复 · 2026-10-02

当前运行资源是 v3：原版 Fogmog 骨架、IK、头部约束及动作时间线，配始源雾菇原画。
旧 `tools/OriginFogmogRig` 却只有 v2 源码。此次保留了当前 v3 的 JSON、图集及贴图
作为可重建输入，并将旧生成器放入 `legacy_v2`。

## 原因与处理

- 七个爪子原本是刚性贴片，手掌却使用混合权重。极端动作里同一爪根两侧最大相差
  89.177 个骨骼单位。爪子现为加权网格：根部采样手掌权重，尖端通过七个以原画
  爪根为中心的小骨骼保留卷曲动作。
- 腿和脚使用不同权重，脚踝处会错开。两张分件现在共用连续的脚踝权重场，肩部和
  髋部的重叠区域也平滑接入躯干。
- 躯干补绘含旧肩部、腿部的三角形残片，动作展开后露出硬边。已裁去被遮挡的多余
  补绘，同时保留待机姿态中暴露的原画像素，清除手掌层的孤立爪缘碎片。
- 眼睛、眼皮和嘴部贴片跟随躯干曲面，继续使用原版眨眼、闭嘴贴图切换。

50 根原骨骼、27 个槽位、IK、变换约束、原骨骼时间线及特效事件保持一致，另外增加
7 根爪尖骨骼。场景位置、尺寸、攻击/召唤/治疗时序及战斗逻辑没有调整。
