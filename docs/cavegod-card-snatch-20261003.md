# Cave God 独立偷牌动作 · 1.10.5

偷牌回合现在使用独立的探掌窃牌动画。Boss 抬起主攻臂、张掌伸向玩家，在接触位置握拳，再攥着卡牌收回；普通与愤怒形态均有左右手版本。

## 动作与呈现

- 新增四段 `card_snatch` 动画，时长 3.2 秒；原有 52 段动作保持不变。
- 0.66 秒前完成抬臂张掌，1.04 秒接触，1.28 秒合掌偷牌；后半段包含收臂和短暂停顿，便于看清被攥住的牌。
- 左右前臂的长度与绑定姿态不同，手腕通过原生 Spine 求解，使用连续展开角度；底层 FK 保留待机角度，保持进出 IK 的衔接。
- 手掌落点根据活着的目标玩家中心调整，偏移只影响呈现。多人每人一张牌，在同一闭合帧进入拳头。
- 卡牌位置与旋转跟随腕骨，文字部分被拳头遮住，牌面露出；多张牌呈小幅扇形。持牌手在待机时保持握拳，直到卡牌归还。
- 沿用现有原画、手掌附件和偷牌优先级。原来的 `FRONT_SWEEP` MoveId 保留以兼容状态和本地化，显示名改为「探掌窃牌 / Grasping Theft」。

## 时序与兼容

按动画绝对时间等待接触与合掌，扣除原版伤害命令内部等待。即时模式主动提交接触姿态，并结束尚未推进的入场混合，防止仅时间戳前进、骨骼仍留在待机。

偷牌使用原版 `CardPileCmd.RemoveFromCombat(IEnumerable<CardModel>)` 一次移除多人选中的牌，在其视觉等待期间就把牌附到拳头上。完整保留原版牌堆更新、移除 Hook 和归还流程；不跳过手牌的原生清理动画。

## 验证结果

最终偷牌回归通过：两侧、两种形态的张掌/握拳附件正确；120 Hz 采样下，左臂最大单帧位移 13.87 px、转角 2.37°，右臂 12.09 px、2.11°。牌在腕骨局部坐标中的漂移小于 0.001 px。使用原版 Ironclad 呈现时，闭合掌心与角色受击中心相距约 23–24 px。

18 种实际命令组合均在 1.04 秒接触、1.28 秒出现被偷的牌，每位存活玩家恰好一张；即时模式也检查真实拳头坐标，避免仅推进时间戳而仍显示待机。完整 Cave God 战斗行为回归通过，包括偷牌优先级、手牌回退、满手牌归还、多人、破臂与阶段转换。
