# 1.14.2 · 双生子场景玩家站位

按用户要求，将菌根双生子遭遇中的全体玩家下移 60 个场景像素（以 1920×1080 为参考），让脚部落在前方平整地面。单人原生脚底高度由 740 调整为 800。血条、名字、受击区域与角色节点一起移动。

使用 `NCombatRoom.PositionPlayersAndPets` 的窄 Harmony 后置补丁，在原版排列完成后移动全体玩家及其随从。每次重排由原版先重设位置，因此不会累计偏移；前后排间距、横向排列和局部玩家优先级仍由原版负责。只匹配 `MycorrhizalTwinsElite`，不改写其他遭遇或全局相机。

复用原生画面探针查看 1／2／4 人队形。单人、双人前排脚底 Y=800；四人前排 Y=800、后排 Y=680。所用人物为原版铁甲战士；实现没有角色类型判断，其他玩家角色使用同一原版排列入口。多人画面属于本地原生预览，未宣称实际联网试玩。

v111 原生画面与既有行为检查 96 项通过。v111／v107.1 Release、Harmony 目标和统一包检查通过，两版均识别 101 个模型。素材 PCK 沿用已验证的 1.14.1 资源。

实现：`STS2_Things/Hooks/MycorrhizalPlayerLayoutPatch.cs`。

已安装 1.14.2，并在 v0.111.0 单人实机进入双生子遭遇。角色脚部与怪物更接近同一地面高度，血条随整个人物下移，与手牌区域保持间隔。实机截图：`build/twins_player_layout/live.png`。

单人及多人预览：`build/twins_player_layout/visuals/`。发行包：`dist/v1.14.2/STS2_Things-1.14.2.zip`。
