# 1.13.2 · 蛾丝缠绕卡牌

按用户要求，牵丝的形状改为真正绕过卡牌的丝束。四道不对称的正面丝束交错覆盖插画，在牌边转弯，底部两道较松的丝线收拢到小结与散丝。纤维有粗细变化、局部高光和交叉遮挡暗部，避免只有卡角装饰的观感。

保留 1.13.1 的原版 Affliction 渲染流程：Queen 的卡牌遮罩、RG/A 纹理通道、独立材质、卡框流光和 GPU 微粒。形状由 `scripts/build_silk_card_overlays.py` 生成，图形使用卡牌坐标设计；没有恢复旧版自定义绘制圆环。Queen 本身的资源保持独立。

施加时用 0.55 秒轻微收紧并闪亮；解除时用 0.48 秒溶解、向外松开。丝线主要覆盖插画和边缘，保留费用、牌名及规则文字的可读性。保留 1／2 顺序标记。

玩法保持原有规则：玩家获得牵丝 buff，下回合正常抽牌完成后随机绑定两张合适的手牌；先打出 1 才能使用 2，解开不减费。
