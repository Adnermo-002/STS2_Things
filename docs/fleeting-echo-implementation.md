# 余影魔实现记录

当前项目包版本：1.25.2。骨骼精修见 [动作制作记录](fleeting-echo-animation-polish.md)。

## 内容

- 深处新增单体弱遭遇 `FLEETING_ECHO_WEAK`，原有弱池扩至 8 个条目；不加入强怪池或其他章节。
- 单人基础生命 999，5 次行动；已承接项目的 [第二章数值校准](depths-balance-20261006.md)，当前普通攻击依次 26、31、36、41、46，致命敌人进阶为 30、35、40、45、50。第五击结算后走原版死亡、场景清理和奖励流程；玩家已经战败时不会继续倒计时或产生第二次结束结果。
- 「借影」在原生 `AfterDamageGiven` 中按实际生命损失返还格挡，使用原生 `CreatureCmd.GainBlock`。多段逐段结算，中毒和荆棘不触发；奥斯提等召唤物返还给所属玩家，多人各得各的格挡。
- 原生 `GainBlock` 会在战斗结束时停止增加格挡。持续战斗中的致死攻击会返还有效生命损失，超杀不计；击杀最后一只敌人后不绕过原版结束规则。
- 「消逝」用原版 Counter 能力显示 5→4→3→2→1，完成一次攻击减一；额外眩晕不会凭空消耗一次攻击。
- 原版单次攻击意图、血条、能力显示和中英本地化；两条玩家可见能力描述保持简短。

## 美术与骨骼

下面保留首版制作记录；当前骨骼已精修为 84 根骨骼、22 层网格，并通过连续变形和原生播放检查。

使用用户指定的 `gpt-image-2.5-sunburst` 和已授权的 API，经 imagegen skill 的官方 CLI 制作。原画、两种能力图标、白色反色调整的提示词和日志均保存在项目中，没有生成专用 SDK 程序。

以一代倏忽魔为轮廓参考、二代原版怪物贴图与能力图标为画风参考。根据后续要求，将暗蓝躯干和金色裂隙反转为象牙白躯干、灰紫折面、深蓝紫负形裂隙。保留四臂、无头躯干和长指，气质沉静诡异；不是呆萌幼体。

美术自审修正了外缘雾光与反色图透明度导致的指端缺口。最终使用已确认原轮廓约束白色图的 alpha，保留干净边界和原来的骨骼位置。两个能力图标、返还格挡的残影以及战斗记录图标同步反色。专属遭遇使用已有原创紫色洞穴成套背景与新区域地板。

Spine 4.2：55 根骨骼、6 层加权网格、12 个动作。四臂各自控制肩、肘、腕和三根指端，躯干及两条拖尾分别加权。五次攻击为探身、横扫、攫取、震荡、散形，接触事件为 .52/.58/.62/.64/.70 秒，另有待机、受击、召唤、强化、复活与消散。外缘剥落 shader 只改画面，不改变命中框；材质按实例独立，初始状态不产生噪点缺口。
