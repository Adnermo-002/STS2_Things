# 始源雾菇动作表现 · 1.10.8

始源雾菇以深蹲蓄力、跨步发力、宽菌盖惯性和爪击的大幅轨迹表现巨型菌木的重量。维持原画、原有骨架与已修复的蒙皮，死亡和复苏仍使用原始动作。

## 动作设计

- 挥爪：转身蓄力，领先脚迈出，身体跟进横扫，后脚接力承重，再分步退回。躯干旋转范围约 45°，身体前移 50 个骨骼单位。
- 头槌：连续短步逼近，双臂收起，菌盖随身体前压碰撞。身体前移 95 单位，菌盖支点在命中时前移约 214 单位；爪尖保持在地面上方。
- 三连击：横扫、上挑、抬爪下劈，三个命中高度不同。第三击蓄力时爪子放在身体外侧，保证轮廓清晰；连击期间逐步前进，完成后分步归位。
- 召唤：下蹲后张臂跃起并释放孢子，身体上升约 52 单位。双脚落地时触发两侧尘雾，躯干继续下沉缓冲，菌盖延后回摆。影子与尘雾发射点始终位于地面。
- 恢复、施法：更明显的压低重心、胸腔膨胀与张臂吐息。孢子从菌盖向上散开。
- 待机与受击：待机保留重心转移、呼吸、眨眼和手臂跟随；受击增加身体后仰及菌盖回弹。

| 动作 | 时长 | 关键事件 |
| --- | --- | --- |
| 挥爪 | 1.70 秒 | 0.64 秒命中 |
| 头槌 | 1.85 秒 | 0.80 秒命中 |
| 三连击 | 2.45 秒 | 0.48 / 0.94 / 1.40 秒命中 |
| 召唤 | 2.40 秒 | 0.82 秒释放；1.20 秒落地；1.28 秒最大落地缓冲 |
| 恢复 | 2.10 秒 | 0.68 秒释放 |

游戏命令保留原生攻击及伤害逻辑，三连击仍为一次多段攻击。行动完成前等待当前动作的回位结束；即时模式直接提交结束姿态，受击或死亡打断时保留新的动画状态。孢子释放与落地尘雾使用不同事件，避免空中扬尘。

## 重建与检查

动作源文件为 `tools/OriginFogmogRig/v3/motion.mjs`。各脚独立设置抬起、移动和着地轨迹，根节点跟随重心移动，原有 IK 保证足部到达目标。使用 120 Hz 曲线采样，菌盖延迟跟随，动作末端与待机的所有骨骼变换保持一致。

```powershell
.\tools\OriginFogmogRig\rebuild.ps1 -Deploy
.\scripts\test-origin-fogmog-actions.ps1
.\scripts\test-origin-fogmog-actions.ps1 -Preview
```

证据目录为 `build/origin-fogmog-impact-20261003/`，包含改动前备份、构建日志、战斗时序检查和原生 Godot 渲染。测试脚本支持 `-OutputDir`；预览从实际动画读取时长。

- 接缝检查：十段动画共 2,754 个姿态，九处连接均通过；脚踝最大分离约 0.534 单位，爪根小于 0.001 单位。
- 动作检查：落脚时不滑动、抬脚时跟随独立轨迹，影子和尘雾不离地，手臂不伸缩，爪尖不穿地，所有动作完全回位。同时检查位移和速度变化，并设置幅度下限及三连击高度差，防止动作退化成小幅摆动。
- 原生战斗检查：1／2／4 人 × 普通／快速／即时模式 × 四种攻击，共 36 组；校验命中动画时间、伤害、攻击命令次数、完整收招，以及孢子方向、落地事件和打断清理。人数场景由测试宿主模拟，未进行真实网络联机人工实战。
- 几何渲染：全部十段动画共 236 帧，没有检测到达到阈值的脱落碎片；原生场景另输出 541 帧、30 FPS 连续预览，包含孢子和落地效果。
- 发布检查：V107.1 与 V111 均编译通过，零警告／错误；统一包分别加载两个实现成功；源码／PCK 审计及 Fogmog／幻象全部动画播放检查通过。
