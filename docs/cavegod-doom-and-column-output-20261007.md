# 双臂 Doom 卡死修复与人面柱合计输出 — 1.25.8

本次修复活体巨岩双臂 Doom 卡死、黑暗镣铐永久减力量及首次暴露时另一只手无法攻击的问题，并按用户指定的整根柱子输出目标降低人面柱攻击。保留已有生命、格挡、虚弱、坍落规则及所有资产。

## Doom 的实际复现与根因

在真实 v0.111.0 游戏、独立测试身份 `125020`，给左右臂各施加 999 Doom 并结束回合。双臂正确恢复到 1 点生命、核心暴露，但战斗停在敌方第一回合，操作被禁用。日志明确报告：

```text
Combat #1 turn loop died while its combat is in progress
System.InvalidOperationException: Sequence contains no elements
DoomPower.ShouldDoomTrigger -> Enumerable.First
Hook.BeforeSideTurnEnd -> CombatManager.EndEnemyTurnInternal
```

原版先收集本轮 Hook 监听者。第一只手的 Doom 回调同批处理双臂，两臂各自的击倒逻辑会清除自身 Doom。原版 `PowerCmd.Remove` 将能力移出拥有者，却保留该实例的旧层数。随后已收集的第二个 Doom 实例仍有 999 层、拥有者恢复到 1 点生命，于是继续判定为 Doom 目标；此时两只手的活动能力均已移除，原版对空目标列表调用 `First()`，使整个回合任务退出。

单独调用 `DoomPower.DoomKill` 的测试不能覆盖后续旧监听者，因此最初模型测试通过。改为分派完整原生 `BeforeSideTurnEnd` Hook 后，旧 DLL 在离线测试中也稳定抛出同一异常，形成了可重复的失败／通过信号。

修复只改 `ThingsCaveGodHand.ClearDebuffs`：遇到 Doom 时先通过原版 `SetAmount(0, silent: true)` 归零即将清除的实例，随后仍调用 `PowerCmd.Remove`。旧回调看到 0 层便安全退出。其他减益仍保持原清除逻辑；没有捕获并吞掉原版异常，没有补丁替换 Doom 或战斗回合，也没有新增 Harmony。

原生回归覆盖 1／4 人、一／二阶段、左先／右先、敌方回合结束 Hook、即时 Doom、已移除实例的重复回调、核心暴露和完整手臂恢复。两个版本均通过 62 项断言。活体巨岩完整行为回归在 V111 通过，包含中毒、反伤、抓取、偷牌、恢复和最终死亡。

失败与复验日志在 `build/cavegod-doom-20261007/`。实机使用独立测试存档，未改变用户进度。

## 整根人面柱输出

普通和高进阶均为磕碰 **10**，震击 **5×2**。每个攻击层总计 10，因此三个可见层全部攻击时也只合计 30。完整柱子的四回合错峰循环为 **10、10、20、20**，平均每回合 15；旧 1.25.6 常规循环为 16、16、32、32，平均 24，降低 37.5%。

验证通过原版伤害命令执行整根柱子的行动，而非只读每层字段。A0／A20、1／4 人下，八轮的每名玩家合计输出均为 `10,10,20,20,20,0,0,30`，其中第五轮开始击碎底层并补位。控制和眩晕造成的零输出窗口保持正常；额外强制对齐三层的磕碰／震击，均合计 30。这里统计柱子自身基础输出，不包含同行怪物或外部力量／易伤修正。

本轮没有降低柱层生命、格挡、虚弱或改变“原中层眩晕”的规则。原生意图和实际结算使用同一伤害值。

## 黑暗镣铐和另一只手的可选状态

补充反馈也已复现：对健康手臂施加黑暗镣铐，再击倒另一只手使核心暴露，原生回合结束后力量仍为 -9。`CanReceivePowers` 依赖 `ShouldAllowHitting`，而旧实现把所有眩晕手臂都视为不可命中，因而恢复 +9 的原生命令被挡住。对已有正力量的手臂直接清除临时能力，还可能把恢复量删掉，永久损失原本的成长。

修复将“不执行动作”与“倒地恢复保护”分开。未倒地的手臂可以在首次暴露的眩晕回合被选中、受到伤害和正常恢复临时力量；动作仍跳过。已倒地或正在恢复的手臂，以及抓取状态的手臂继续保留各自保护和目标限制。

清除临时减力量时，先结算其恢复量，再清除临时能力；在判断净力量是否为减益前完成这一步，从而保留被 -9 遮盖的正力量。旧临时能力实例归零，避免已排队的回调再次补回力量。恢复使用原版 `PowerCmd.ModifyAmount`，移除使用原版 `PowerCmd.Remove`，没有新增补丁。

新增回归在左右臂、1／4 人、原力量 0／4／12 下验证自然到期、倒地清除、旧回调、实际攻击另一只手和倒地手保护；两个目标各 86 项通过。完整 Boss 行为回归也重新通过；旧测试中“健康手臂眩晕即不可选”的断言已按新要求改为“眩晕跳过动作但仍可选”。

最终统一包在真实 V111 游戏复验：对右臂施加原版黑暗镣铐能力并击倒左臂，下一玩家回合右臂力量回到 0、处于 `WEAK_STUN` 却仍可命中；实际打出打击，将其生命由 50 降到 44。随后重开测试遭遇让 Doom 同批击倒两臂，也正常进入第 2 玩家回合并得到 6 张可操作手牌，未再发生回合任务异常。测试通过原版格挡命令保护玩家，仅验证机制，不验证胜率。

实机控制台直接在第一章测试 Boss 时仍出现已有的 Kaiser 音乐路径诊断，未改音乐资源；该诊断不影响本次回合、力量与攻击复验。相关 stderr 保留，未宣称游戏日志完全无诊断。
