# 1.12.3 · 冲净状态牌过滤与原版风格能力图标

冲净保持原生 Buff。每层自动消耗下一张通过抽牌抽到的状态牌，最多 2 层；适用于寄生、灼伤、伤口、晕眩、黏液和虚空，诅咒及普通牌不触发。沿用原版抽牌与消耗命令，先扣冲净再触发消耗，支持黑暗之拥等连续抽牌效果。

寄生卡面已移除水蛭变招说明，只保留回合末留手给予再生和力量的效果。水蛭的原生「顽固寄生」能力负责显示与触发该反应；仅寄生被消耗时准备补牌，其他状态牌被冲净不会引起变招。原有同一行动前合并请求、眩晕优先和死亡过滤继续保留。

## 图标重绘

使用 imagegen 技能的官方 CLI，经用户指定接口与 `gpt-image-2.5-sunburst` 生成五个图标：吸水体质、积水、冲净、致盲、顽固寄生。以原版蜷身、覆甲、人工制品、虚弱、脆弱、再生等能力图标作为风格参考。

最终采用粗深色轮廓、单一符号和两至三块主要平涂颜色。移除原来的怪物缩略图、发光水球、碎小水泡和花屏条纹。已查看生成原图、透明抠图、256px 大图、40px 缩略图以及原生战斗渲染，轮廓、色块和实际尺寸的辨识度符合这套原版 UI。

原图、最终透明图、提示词和生成记录：`source_assets/ui/depths_icons_v2/`。最终联系图为 `final_contact.png`，上排为大图，下排为 40px 实际尺寸。游戏资源提供 256px 与 64px 版本，由 `scripts/prepare_depths_power_icons.py` 重建；水蛭、灯笼鱼和海绵的资源准备脚本均引用同一份选定图标。
