## 防御与成长

- 鱼守势 12 → 9，水蛭蜷缩 8 → 6，海绵吸水格挡 10／12 → 8／10。
- 晶壳初始／缩壳 8／10 → 6／8；爬岩初始壳 6／8 → 5／6、爬行壳 4／5 → 3／4；涎丝修壳 7／9 → 5／7。
- 洞胃初始覆甲 12／14 → 10／12。投食仍为两张保留碎屑，吞食与力量上限保留。
- 人面柱封印格挡 14／18 → 10／14，虚弱 2 → 1。未破层时通常合计 8–16，三层同时攻击最多 24；底层被击倒时仅原中层眩晕。
- 双生子基础护根 14／16 → 11／13；丰盛／萎蔫战孢 4／2 → 3／1，菌甲 4／2 → 3／2。形态倍率和同伴死亡的四点力量保留，真实意图仍包含形态与力量。
- 蝾螈打出回流牌给予力量 2／3 → 1／2；聚潮格挡 16／20 → 12／16。力量提示改用原生动态说明，随进阶显示实际值。
- 水母每层收音的伤害／格挡加成 2 → 1；调频格挡 16／20 → 12／16，仍按既定循环强化层数和收录攻击／技能。

寄生仍为每张两层再生与两层力量；致盲抽牌数、缠丝两张牌、海绵每损失 10% 生命蓄水和喷后 10% 回血、破壳奖励与延迟规则保留。
