# 馋嘴洞胃吞牌残留修复

2026-10-06；模组版本保持 **1.25.0**；当前实机版本为 Steam 正式 **v0.107.1**。

## 根因与修复

洞胃的 `Devour` 使用了 `CardCmd.Exhaust(..., skipVisuals: true)`。这个参数不只是隐藏消耗粒子，还跳过原版牌堆通知及手牌节点退场：数据已进入消耗堆，原来的 `NHandCardHolder` 和 `NCard` 却留在手牌中，仍能被拖到半空。洞胃额外创建的吸入卡牌副本本身可以正常释放。

恢复默认的 `CardCmd.Exhaust(context, card)`，由原版管理手牌移除、拖牌取消、消耗触发和节点释放。保留吸入嘴里的装饰动画、最终牌堆检查、吞牌数量及强化数值；未添加全局清理补丁。
