# 放缩巨甲虫动作增强 · 1.10.9

保持原画、54 根骨骼、24 个槽位、原网格与权重，强化巨型硬甲昆虫的全身发力。硬甲保持刚性，六足采用独立落脚轨迹，触角保留分节惯性。

## 动作与战斗

- 撕咬：后撤张颚蓄力、蹬地前冲、前足与中后足依次跟进，结束后分三组退回。身体水平行程约 140 原画像素，颚部在 0.68 秒咬合，完整时长 1.95 秒。
- 鞭打：近触角抽打、远触角反抽、双触角重扫组成一段 2.75 秒的连续三连击。身体反向承力；命中位于 0.60／1.12／1.68 秒。
- 重构化：深蹲后抬头、抬前足并张开触角，在 0.76 秒开始施加放缩，2.30 秒完成回位。
- 蜕壳：六足分组调整支撑，胸甲抬升，外甲显著张开、震动、回落；0.80 秒获得格挡，随后施加放大，2.65 秒归位。
- 强化、受击、登场：增加低伏、昂首、前足缓冲和触角跟随。死亡伏地与复起衔接保留；影子跟随身体的水平位移并保持着地。

命中依然通过一次原生 `AttackCommand` 执行，保留伤害、次数、格挡、放缩层数、音效与战斗 Hook。动画绝对时间用于对齐结算，行动结束前完成收招，快速与即时模式同样提交关键姿态。

三连鞭的两个后续蓄力点可等待原生结算：命中后给玩家施加缩小时，尤其在多人普通速度下，后续鞭击不会提前播完。`NThingsScaleBeetleMotion` 仅在游戏主动控制连击时启用等待；独立预览完整播放，受击／死亡切换解除等待。

同时补齐甲虫被动、放大、缩小三个状态栏图标。小图由现有 256 像素原图缩至 64 像素，未重新绘制美术。

## 验证

- 官方 Spine 4.2.43 运行时：全部十段动画共 2,981 个姿态。活体动作至少三足支撑，落脚目标最大误差约 0.909 原画像素；头部、双颚和触角不穿地，甲壳不拉伸，发光层沿用宿主网格。
- 待机闭环与死亡／复起衔接误差为零，动作末端回到初始姿态；设置动作幅度下限，避免变成小幅摆动。
- 原生 Godot 渲染：757 帧彩色画面与 511 帧轮廓检测；未发现达到阈值的脱落分件或镜头裁切。
- 原生战斗宿主：1／2／4 人 × 普通／快速／即时 × 撕咬／鞭打／重构化／蜕壳，共 36 组。包含实际的“命中后缩小”被动，检查伤害、三次接触时间、能力层数、原生多人格挡缩放、完整收招、状态栏图标、蓄力等待及打断后的恢复。
- 人数由测试宿主模拟，未进行真实网络联机人工实战。
- V107.1／V111 编译均为零警告、零错误；统一包加载、源码／PCK 审计、全部场景动画与四种外部缩放检查通过。
