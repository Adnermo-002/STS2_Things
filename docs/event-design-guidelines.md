# 自制事件设计规范

用户约定：普通事件一般以小额纯增益代替空白「离开」；2026-10-06 补充，无损选项按主题设计，不统一奖励 15 金币。

- 为自制普通事件提供符合主题、无需付出资源的小收益选项，例如少量回复、免费药水或少量金币。收益量结合所在章节和其他选项决定；`DepthsEventDefaults` 中的 15 金币仅供适合给钱的分支使用。
- 已有免费奖励分支时，可直接将其作为无损选择，无需再加一项通用奖励。检查获得限制；例如无法获得药水时，提供主题相符的替代收益，并锁定无法兑现的交易。
- 分支结算后的「继续」「结束」用于结束已经结算的流程，不再重复奖励。取消选牌应返回选择页面，不以空结局替代收益选项。
- 选项独立清楚，玩家直接看见代价与所得；风险和战斗在选择前写明。洞胃四种喂食直接展开，再提供小收益选择。
- 原版事件文风：第二人称、具体动作、短对白与简短反应；效果说明直接写「移除……。获得……。」。参考当前原版事件表，不用模糊隐喻替代动作和效果。
- 多人先确定选择是否共享。个人交易只改变各自资源；切换战斗使用原版共享事件同步；休息点各自结算，用原版选项协议完成房间。
- 用原生存档属性保存跨房间收益与代价，保留领取标记，处理重复载入、死亡延迟和跨章节情况。
- 每次调整后审查所有可选路径：有合法选择、没有重复领取、没有仅因为缺少资源而卡住；查看中英文与多人排版。验证方式遵守当前用户授权。

此约定适用于自制事件，当前同步到深处事件。原版事件池中的原作事件保持其原有选择。
